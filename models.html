基模

FRONTIER MODELS · SNAPSHOT 2026-11

基模是整条产业链的地基，也是变化最快的一层。这一页分成两层，别混着读：

上面那层是分榜，只放有公开出处的分——Artificial Analysis 的指数、LMArena 的 Elo， 每个分都能回溯到来源，某维度没分就不出现。下面那层是台账，按**发布时间、权重形态、 能力取向**列谁在什么时候把什么能力做进了默认配置，不排名。

两层都在 2026-11 这一版上对齐了：分榜是实时抓的，台账补到 2026-11-18。 口径仍然不同——分榜是第三方测出来的分，台账是发布顺序加人工标注，两者不能互相换算。

三条结论 / VERDICT

  1. 前三名的差距已经压到个位数。Claude Fable 5.2（64.6）、GPT-6.2 Astra（62.1）、Gemini 4 Neon（61.4）挤在 3 分之内，换一家旗舰不再等于换一个能力档，选型的决定权回到价格、上下文和工具链上。
  2. 定价靠「档」而不是靠「代」。Gemini 4 一代里 Neon 是 $3/$15、Carbon 是 $2/$10、Hydrogen 是 $1.5/$7.5，分数 61.4 / 60.0 / 53.9——同一代里最贵的和最便宜的分差 7.5 分、价差一倍多。看「Gemini 4」这几个字判断不了成本和能力。
  3. 开放权重成了主力交付形态，但不是天花板。台账 31 条里 17 条挂出了权重，Kimi K3.1 Pro（46.5）已经是开放阵营最高分；再往上那 15 分，目前只有闭源够得着。

数据限制

  • 台账只收代表作。 同机构的小改版（快照、pro、flash、x 版）不重复列；31 条覆盖 2026-05 到 2026-11，不等于这一年的全部发布。
  • 权重是否开放按「有没有挂 Hugging Face」判断。 这是可核查的近似：厂商把权重放上 HF 就会带仓库 ID，没放就没有。少数只在自家仓库发布的会判成闭源。
  • 榜单分数：只收 AA 与 LMArena 两家有原始表格的；厂商自测的 SWE-bench、GPQA、AIME 不进榜——口径不一，横向排会把人带偏。
  • 分榜覆盖：两家不是全量收录，没进它们样本的模型（尤其中文厂商）会缺席，这是数据本身的缺口，不是「这模型不行」。
  • 价格：本页不列价格表，只在报告里讨论计价方式。同一个模型在不同渠道的挂牌价能差一倍，写成固定数字很快就错。
  • 参数规模：多数闭源模型不公开，开放模型也只写公开确认的量级。

先弄清这几个词

榜上的分只看数字会误读，四张卡各通向原理板块的一篇报告。
01 结构

MoE：总参数与激活参数

总参数决定显存占用，激活参数决定单 token 计算量。看 MoE 模型别只比总参数量——同一句「1T 参数」，跑起来的成本可能差一个量级。

原理 · 05打开 → 02 成本

一次生成到底在算什么

prefill 一次性并行算全量输入，吃算力；decode 每吐一个 token 都要把权重读一遍，吃带宽。长输出比长输入贵，根子在这里。

原理 · 01打开 → 03 训练

推理模型与 test-time compute

把「想」变成显式的 token：先写中间步骤再给答案。用更多 token 换正确率，这笔账要算进单价里，而不是只看每百万 token 的标价。

原理 · 04打开 → 04 部署

量化与蒸馏

量化省显存与带宽，蒸馏省参数与步数。两者常被混着说，代价完全不同：一个掉精度，一个掉能力上限。
