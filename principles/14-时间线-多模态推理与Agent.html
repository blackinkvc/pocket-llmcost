时间线 ④：多模态、推理与 Agent（2023–2025）

三年里三条线并行推进：多模态成为旗舰默认形态，推理从单独产品并回默认路由，Agent 从演示走进 IDE 和终端。2026 年这一段留空待补。

三年里三条线并行推进，而且互相咬合。

多模态从「旗舰才有」变成默认形态，输入侧的语音、视频不再是额外功能。 推理从单独售卖的产品线（o1）并回默认路由（GPT-5），用户不再需要选「要不要想」。 Agent 从演示视频走进 IDE 和终端，编码场景先跑通，因为代码有编译器当判卷人。

开放权重这条线同时在上探：从 LLaMA 到 Llama 3.1 405B，再到 DeepSeek、Qwen、Kimi、GLM， 量级和闭源旗舰的差距从「一代」缩到「半年」。

  • 2023-03 GPT-4 发布：多模态输入与更强的考试能力，闭源旗舰的门槛被抬高。（范式改变）
  • 2023 LLaMA 与开源追赶：开放权重模型让本地部署与二次训练成为可能。
  • 2024-02 Sora 演示 / Gemini 1.5：视频生成展示长时一致性；百万级上下文进入产品讨论。
  • 2024-05 GPT-4o：文本、视觉、语音端到端，延迟大幅下降。（范式改变）
  • 2024-07 Llama 3.1 405B：开放权重第一次接近闭源旗舰的量级。
  • 2024-09 o1：把推理链作为产品——用更多思考 token 换正确率，test-time compute 成为新维度。（范式改变）
  • 2024-11 MCP 开源：工具接入有了统一协议，Agent 生态开始标准化。（范式改变）
  • 2024-12 DeepSeek-V3：以较低训练成本达到接近头部的通用能力，MoE 路线受到关注。
  • 2025-01 DeepSeek-R1：开放权重的推理模型，蒸馏版带动一批小模型具备思维链。（范式改变）
  • 2025-02 Claude Code / Claude 3.7：编码 Agent 从补全走向「读写整个仓库并执行命令」。
  • 2025-03 Gemini 2.5 Pro：长上下文与推理结合，百万 token 成为旗舰标配讨论项。
  • 2025-04 Llama 4 / Qwen3：开放权重进入 MoE 与「思考模式可切换」阶段。
  • 2025-05 Claude 4 / Veo 3：编码 Agent 产品化；视频生成开始原生带音频。
  • 2025-07 Kimi K2 / GLM-4.5 / ChatGPT Agent：开放权重继续上探；通用 Agent 进入消费级产品。
  • 2025-08 GPT-5：快慢思考合并为自动路由，推理不再是单独售卖的产品线。（范式改变）
  • 2025-09 DeepSeek-V3.2-Exp：稀疏注意力把长上下文成本压下来，API 同步降价。
  • 2025-11 Gemini 3 / Claude Opus 4.5 / K2 Thinking：多模态、长任务与工具调用同时推进；开放权重继续逼近。

这三年能看出的三件事

第一，能力提升越来越依赖训练之后。 预训练还在做，但 RLVR 这类后训练手段贡献了大部分可感知的提升。 第二，产品形态在收敛。 聊天框、IDE、终端三个入口基本定型，剩下的竞争在「能连续做多长的任务」。 第三，开放权重和闭源的差距缩到了半年量级。 这改变了选型逻辑：不是「开源行不行」，而是「这个任务值不值得等半年」。
