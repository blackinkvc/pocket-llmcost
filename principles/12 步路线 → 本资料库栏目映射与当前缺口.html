12 步路线 → 本资料库栏目映射与当前缺口

按重要性排，接下来最该补的三块是：提示词工程（本库完全没有独立栏目，只在 T025 阶段四顺带提到 CoT，A022 的 Query Rewrite / Grounded Prompt

以下为基于 A010 的归纳延伸：原文只给学习顺序，没有做资料库映射。因与 T024（路线本身）性质不同，按同板块不同主题并列成卡。目的很实际——你正在搭的这份资料库，可以用这 12 步当体检表。

逐步对照（「已有」指本库当前已有整理稿的板块）：

  • 第 1 步 Python / 前置知识 → 暂无独立栏目；A010 的 T025 阶段一已把 Python、PyTorch、数学基础记下，但本库还没有编程基础类资料
  • 第 2 步 Transformer / 核心原理 → 基模板块：T026（结构 + MoE + LoRA）、T006（推理网关）、T037（高维 Embedding 降维 PCA / t-SNE / UMAP，A016 新补）；A010 已覆盖结构，A016 补上「Embedding 长什么样、怎么判断聚类」的原理直觉，训练细节仍偏少
  • 第 3 步 提示词工程 → 暂无独立栏目；目前只在 T025 阶段四的 ReAct 规划里顺带提到 CoT
  • 第 4 步 RAG → 【2026-11-25 两次补完：替代路线 + 传统工程】A020 新建「Agent 记忆 · 参数化与 RAG 替代」栏目（T044 口径校正 / T045 四层参数与可维护性边界），讲「不再每轮重塞历史原文」的参数化记忆；A022 又新建「RAG 工程 · 大规模检索系统」栏目，T049 全景与规模账 / T050 写入链路 / T051 存储与查询链路 / T052 生产保障，把 T025 阶段三只有名词的 Chunking / Embedding / Milvus·Faiss·Chroma / BM25 / Rerank 清单补成了全链路工程（文档接入 → Kafka 双队列 → OCR 切块 → 5 类存储 → 混合检索 RRF → Cross-encoder 重排 → Grounded Prompt → 评测/观测/重建/权限）。至此第 4 步传统 RAG 架构工程已补，T037 的 Embedding 可视化、T018 的企业知识库选型仍只是相邻不等价。⚠️ 但这是架构知识不是可复现能力：还缺能照着跑的部署配置、具名产品版本、实测 QPS/P95 与真实账单，见 G18 降级项与 rag 板块清单
  • 第 5–6 步 LangChain / LangGraph → 暂无独立栏目；速查表 P48–P49 已记录，缺系统资料
  • 第 7–8 步 Agent / 多 Agent → Agent 板块最厚：T003（编码智能体五层架构）、T012–T014（知识图谱三卡）、T027（商用 AI Agent 教程），另有 T020–T022 关联；是本库目前覆盖最充分的一段
  • 第 9 步 私有化部署 → 硬件板块【已破零】：A011 补入 Fluidstack Blackbird 模块化数据中心（T029 事实 / T030 归纳 + 2 条速查），是基建供给侧；但仍缺 GPU/NPU 芯片、显存带宽、推理加速、PUE 与具体造价数值，T018/T019 的企业知识库选型也只给框架未给数字
  • 第 10–11 步 微调 / 量化 → 基模板块有 T026 的 LoRA 与 T025 阶段五/六的 PEFT、量化名词，缺实操资料
  • 第 12 步 多模态 → 暂无；仅 A007 的 3D 网页视频与 A006 的视觉设计类 Skill 沾边，不成体系

一句话结论：本库目前是「Agent / Skill / MCP / 工具速查」偏重，「基模原理 / 工程底座 / 学习路径」偏轻；硬件板块由 A011 破零、A013 补了「AI Infra · 产业与公司图谱」产业侧栏目、A020 补了「Agent 记忆」、A022 又补上了挂了很久的「传统 RAG 工程」，但离能算清一笔算力账、或能照着代码跑起一套 RAG 仍差具体工程包与真实数字。这套 12 步地图正好可以当后续收资料的导航——每来一篇新文章，除了判板块，也可以顺手标一下它补上了哪一步。

归集规则：以后收到讲 Python / 提示词 / RAG / LangChain / 部署 / 量化 / 多模态的资料，按第 8 条新建栏目或并入本卡映射表，并同步更新这里的「已有 / 缺口」判断。更完整的逐板块待补清单已独立成页：顶部「🧩 补齐清单」视图里有全站待办、板块体检表、逐板块缺口与资料级「内容待补」列表，本卡只保留学习路线视角的映射。
