# 投料区（inbox）

往这个目录里丢东西，跑 `python3 tools/research.py sync` 就会被登记成一条研究。

## 规则

- **一个文件 = 一条研究**：`多智能体编排的三种范式.md`、`某篇论文.pdf` 都算。
- **一个文件夹 = 一条研究**：文件夹里可以放正文、PDF、截图、数据表。适合一份研究配多份原始资料。
- 文件名随意，但**标题请写清楚**——标题直接取自文件名（md 取第一个 `# 标题`，其他格式取文件名）。
- 单个文件建议 < 20 MB。图先压成 webp，别把几十MB的原始截图丢进来（进 git 会给每次 clone 加重）。

## 别放什么

> 这个仓库是公开的：你丢进来的原始资料会以 `research/items/<slug>/raw/` 的形式提交，AI 整理的草稿也在这个仓库里（不上站点，但能翻到）。
> **不能公开的东西不要放进来。**

## 跑完之后

1. 文件会被移到 `research/items/<slug>/raw/`（inbox 清空，留一份 README）。
2. 生成一条 `meta.yml`，状态是「整理中」，站点上出现占位页（noindex）。
3. 再让 AI 整理 → 产出 `draft.md` → 你在页面上点「通过审核」→ 变成正式子页。
