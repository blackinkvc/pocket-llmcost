# 投料区（备用）

**日常投料已经搬到外置盘的 `/Volumes/AI仓库/AI行业研究/`**，那里按站点板块分好了文件夹，丢进去就知道该归哪一类。

这个目录只是备用：外置盘没挂载时，`sync` 会退回到这里读。规则相同（一个文件 = 一条，或一个文件夹 = 一条），只是没有板块归属。

## 规则

- **一个文件 = 一条研究**：`某篇论文.pdf`、`某份对比分析.md` 都算。
- **一个文件夹 = 一条研究**：文件夹里可以放正文、PDF、截图、数据表。
- 标题取自正文第一个 `# 标题`（HTML 取 `<title>`），没有才回退到文件名。
- 单个文件建议 < 20 MB。

## 别放什么

> 这个仓库是公开的：原始资料会以 `research/items/<slug>/raw/` 提交进 git，AI 整理的草稿也在仓库里。
> **不能公开的东西不要放进来。**

## 跑完之后

1. 文件被搬到 `research/items/<slug>/raw/`（这里清空，只留 README）。
2. 生成 `meta.yml`，状态「整理中」，站点出现占位页（noindex）。
3. AI 整理出 `draft.md` → 变「待审核」→ 点「通过审核」→ 正式子页。
