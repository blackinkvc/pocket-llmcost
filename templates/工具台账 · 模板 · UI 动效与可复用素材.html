01 React Bits（reactbits.dev）

创意动效，直接复制；「170+ 个动态背景、文字、光标与 3D 组件，预览、代码和参数都放在一起」，适合 Hero 区与作品集

— 作者：「8 个高级动效网站」01 页（A033 图面） · 平台：WEB · REACT；reactbits.dev（图面抄录）

⚠️ 同图截图写「165+ Free Creative Components」，与正文 170+ 并列不调和；怎么用：保留运动机制，只替换配色 / 尺寸 / 文案，一个页面先放 1 个主效果。未回官网核实。见 T077 / T078 / P158

02 Aceturnity UI（ui.aceturnity.com）

一秒做出高级感；聚光灯 / 3D 卡片 / 背景光束 / 滚动展示，含能直接拼页面的完整区块，适合 AI 产品 / 作品集 / SaaS 官网

— 作者：「8 个高级动效网站」02 页（A033 图面） · 平台：WEB · LANDING PAGE；ui.aceturnity.com（图面抄录）

⚠️ 专名按图面原样抄（Aceturnity 拼写未核），不校正为常见写法；「一秒」是宣传话术。怎么用：说清保留哪个动效、替换哪些视觉内容，先复制一个区块跑通再统一圆角 / 字体 / 颜色。见 T077 / G33

03 Magic UI（magicui.design）

克制但不无聊；列表进入 / 数字增长 / 动态边框 / 状态反馈，适合后台、工具与产品页

— 作者：「8 个高级动效网站」03 页（A033 图面） · 平台：WEB · PRODUCT UI；magicui.design（图面抄录） · 开源：图面写「150+ 个开源 React 动效」（许可未给）

⚠️ 150+ 是图面宣称、未回一手核实；怎么用：先让 AI 完成静态页面再逐个加动效，优先首次进入 / 关键操作 / 状态变化，统一时长与缓动。见 T077 / T078

04 Codrops（tympanus.net/codrops）

高阶动效实验室；WebGL / GSAP / 图片变形 / 滚动叙事 / 页面转场，收录普通组件库找不到的实验性效果

— 作者：「8 个高级动效网站」04 页（A033 图面） · 平台：WEB · CREATIVE CODE；tympanus.net/codrops（图…

怎么用：只挑一个运动机制让 AI 复现、不要照搬整套视觉；上线前补移动端降级 / 加载占位 / reduced-motion。⚠️ 这是全篇唯一显式提「reduced-motion」的一页，按图面留档不扩写成通用规范。见 T077

05 LottieFiles（lottiefiles.com）

手机端轻动效宝库；加载 / 成功 / 空状态 / 引导 / 品牌动画，可预览与调整颜色，支持 Web / iOS / Android

— 作者：「8 个高级动效网站」05 页（A033 图面） · 平台：WEB · iOS · ANDROID；lottiefiles.com（图面抄录）

⚠️「体积小 / 接入快 / 跨端表现稳定」是定性话术，无数值。怎么用：按语义搜 success / loading / AI thinking，下载 Lottie JSON 交给 AI，并补充何时播放 / 是否循环 / 播放几次 / 结束后停在哪一帧。见 T077 / T078

06 Page Flows（pageflows.com）

看真实操作和转场；展示真实产品完整操作录像而非静态截图，Web 与手机流程都有

— 作者：「8 个高级动效网站」06 页（A033 图面） · 平台：WEB · MOBILE FLOW；pageflows.com（图面抄录）

怎么用：搜 onboarding / 购买 / 订阅，边看边记「触发—过渡—结果—大致时长」四项连同截图交给 AI，实现后对照录像逐帧调节奏。⚠️ 总览图没有画这个 logo，只在逐页图出现。见 T077 / P148

07 Mobbin（mobbin.com）

真实产品状态库；「40 万+ 移动端与 Web 截图」，可连续查看同一流程的不同状态，确认动效前后界面元素改变了什么

— 作者：「8 个高级动效网站」07 页（A033 图面） · 平台：WEB · iOS · ANDROID；mobbin.com（图面抄录）

⚠️ 40 万+ 是图面宣称、未回一手核实；图面自己说明「不是纯动效库」。怎么用：选状态 A / B 让 AI 还原布局，再描述哪些元素移动 / 消失 / 被替换，节奏不确定时配合 Page Flows 录像。见 T077 / T078

08 Recent.design（recent.design）

追最新动效趋势；「每天更新 Web / Interface / Motion / 3D 案例」，适合项目早期判断流行方向与克制 or 张扬

— 作者：「8 个高级动效网站」08 页（A033 图面） · 平台：WEB · MOTION · 3D；recent.design（图面抄录）
