逆向工程：把闭源产品拆开的人

6.7 万星的 gpt4free、5 千星的剪映草稿库、把 Claude Code 订阅接到别家模型的代理——这类项目做的都是同一件事：读懂闭源产品的接口或文件格式，然后绕开它。它们不是商业模式，是价格发现机制。

一句判断：逆向工程不生产能力，它只做一件事——把「你的入口」变成「一个可以绕开的接口」。

闭源软件的价格里，有一部分是功能，有一部分是锁定：你的素材在它的工程文件里，你的工作流在它的界面里，你的团队在它的协作空间里。逆向工程拆的就是这部分。

三种做法，三种风险

做法在拆什么代表项目失效方式
逆向接口网页端 / 客户端的私有 APIgpt4free（6.71 万星）上游改鉴权、加风控，适配器当天失效
逆向文件格式工程文件、草稿、导出包pyJianYingDraft（4972 星）官方把格式加密或改成二进制
逆向交互用 UI 自动化点别人的软件pyJianYingDraft 的批量导出控件改版、平台限制

gpt4free：把 50 多家模型的网页接口收进一个客户端

6.71 万星、1.35 万 fork、GPL-3.0。它的做法不是破解模型，而是把各家网页版背后的接口逐个适配，包成 OpenAI 兼容的 API，再配一个网页界面。价值主张很直白：不用付 API 费。

代价也很直白：违反各家服务条款、随时失效、依赖极少数维护者。这类项目的 README 里通常有一段「收到删除通知就下线某个适配器」的说明——它自己知道边界在哪。

pyJianYingDraft：把剪映的草稿变成可编程的

4972 星、Apache-2.0、纯 Python。它不剪片，只生成剪映能读的草稿文件（draft_content.json），让你用代码批量塞素材、写字幕、调轨道，最后仍然在剪映里检查和导出。

这个项目的意义不在技术难度，在于它揭示了一件事：剪辑软件的护城河有一半是工程文件格式。 一旦格式能被读写，批量混剪、模板化生产、自动字幕这些活就可以脱离界面完成。它也解释了短剧行业为什么能把单剧人手从四五十人压到四五人——不是 AI 会剪片，是组装这件事被脚本接管了。

而且它已经把边界写在文档里：自动导出只在 Windows + 剪映 6 及以下版本有效，新版剪映（10.8）的 draft_content.json 往往不是可直接读取的明文 JSON，需要 fallback。这就是厂商的反制——不改功能，改格式。

claude-code-router：把订阅接到别家模型上

1.8 万星。它读的是 Claude Code 的接口协议，让你把它的「大脑」换成 DeepSeek、Kimi 等更便宜的模型，界面和工作流不变。

这个方向的商业含义比 gpt4free 更清楚：它证明编码 Agent 的价值有一大半在脚手架，不在模型。同一个月费，换个后端就能把成本压下来——厂商卖的是工作流，模型只是可替换件。

另一类：不是逆向，是复刻

容易被混在一起的是「照着商业软件做一个开源版」。它们不拆你的代码，只是把你的功能重做一遍：

项目复刻对象形态
PenpotFigma开源，自托管，SVG 原生
PhotopeaPhotoshop免费（广告 + 订阅），浏览器内运行，闭源
Krita + 各类生成插件Photoshop 的修图流程开源，靠插件补生成能力
DaVinci Resolve 免费版Premiere 的调色与剪辑免费闭源，靠硬件和工作室版收钱

复刻和逆向的区别在于合法性与可持续性：复刻是重新实现，可以堂堂正正收费；逆向是搭在别人的接口上，别人一改就得跟着改。

为什么这类项目在 2026 年变多

三个条件同时成立：模型能读懂混淆过的代码和二进制格式；开源社区有了分发渠道（GitHub + 一键部署）；闭源产品的价格没有跟着成本下降。

结果是一种很奇怪的局面：厂商一边降价、一边加密、一边把自己的功能塞进别人的入口。 Adobe 把 Creative Agent 做进 Claude 和 ChatGPT，就是这个逻辑的正面版本——既然拦不住用户去别处，那就把自己变成别处的一个工具。

风险，说清楚

  • 法律：违反服务条款是确定的，是否构成侵权要看辖区和具体行为；反向工程在部分司法区受保护，但「绕过技术保护措施」通常不受保护。
  • 账号与数据：这类项目普遍需要 Cookie 池、账号池或代理，用别人的账号跑自己的流量，风险和收益完全不对等。
  • 供应链：几万星的项目也可能被投毒，装之前看依赖、看构建产物，别直接在生产机上跑。
  • 稳定性：所有适配器都是「上游不改就还能用」，不能作为业务依赖。

结论

逆向工程不是一门生意，它是市场的一个温度计：当一件东西的价格明显高于它的可替代成本时，就会有人去拆它。 拆得动，说明锁定不牢；拆不动（格式加密、协议私有、法律高压），说明锁定还在。

对买方，这类项目最实际的用处不是省那点钱，是知道自己的议价空间在哪——你能被替代的那部分，才是你真正在付钱的部分。

已知的取舍

  • 星标不是用户数。 6.71 万星里绝大多数只是收藏，真正跑起来的比例没有数据。
  • 星标是当天快照。 本页数字取自 2026-11 的公开页面，这类项目涨落很快。
  • 不推荐在生产环境使用。 本页是现象记录，不是使用指南；涉及绕过付费与鉴权的部分，明确不建议。
  • 没有收录已下架项目。 这一领域有几个曾经很知名的仓库已经因删除通知消失，无法核对星标，故不列入。
