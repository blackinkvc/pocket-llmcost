H02 / H03 · 「OpenAI 破解数学」与「Claude 解决黎曼猜想」：标题简写与形式化核验

⚠️ 本卡是用户点名后回一手核实补齐的历史事件，不是用户收录的 A 台账：用户只给视频 + 两个短语「openai破解数学」「Claude解决黎曼猜想」，没有链接或文件。

H02「OpenAI 破解数学」其实是 2026 年 9–10 月三串独立事件：① 09-08 约 1 万个并发智能体、约 88 小时给出纳维–斯托克斯存在性与光滑性问题证明，166 页论文 + Lean 代码（GPT-6 Astra 再用约 17 小时形式化）；约 490 万条消息 / 3000 亿输出 token，其中约 270 万条 / 1300 亿 token 花在该问题；解是「螺旋向内、不断拉长的涡旋」；放弃申领 100 万美元千禧年奖；因 Buckmaster（NYU）与 Alpöge（Anthropic）早约 12 小时公开相近成果引发优先权争议，OpenAI 称未看其成果、但不完全排除产品数据以某种方式参与训练。② 10-07 GitHub 一次放出 722 篇数学手稿（同一未公开内部模型、17 个分支），称尝试约 4000 个未解问题、在 372 组上拿出结果，平均每个结果算力≈ChatGPT 付费高级版思考 3 小时；目录加摘要约 40 页，至今无人通读（OpenAI 自己也没有），数学家陆续发现有的证明错了、有的读不懂、有的连机器检查都没做过；平面点集染色声称「5 种不够，只剩 6 或 7」；《科学》口径的拟黎曼猜想（7/8 到 1 之间无零点）。③ 10-26 宣布全维度挂谷猜想（局部平滑猜想成立）、推翻 ETH 指数时间假设、杨–米尔斯 / 四维规范场严格数学证明，已上传 GitHub 并邀请 Impagliazzo / David Gross 评审，仍待严格同行评审。

H03「Claude 解决黎曼猜想」的准确说法：2026-11-20（黎曼诞辰 200 周年研讨会深圳开幕当天），34 岁的 Anthropic 数学家 Levent Alpöge（普林斯顿博士、导师 Manjul Bhargava，2026 入职 Anthropic）在个人网站发 4 页声明：「我相信，我和 Claude 一起找到了黎曼猜想的一个证明」；扩展到 GRH 广义黎曼猜想一个版本（狄利克雷 L 函数）。无论文 / 无投稿 / 无期刊评审，随附 14 个压缩包、超 1700 万行 Lean 代码；Claude 整理的论文 >25 万页（Claude 称「GRH 之书」）几乎不可读，故只公布代码；作者自承未吃透全部原理。声明附 20 步时间线，最早 10-06「OpenAI 一次性放出 722 篇数学手稿」，最后 11-16 只有「GRH」，前后约六周；黎曼猜想自 1859 年悬置 167 年，克雷研究所悬赏 100 万美元。

独立验证与学界回应（一手 / 权威转载）：MIT 数学家 Andrew Sutherland 独立下载编译通过，称只调用 3 条最基础标准公理、「有猫腻的可能性约等于零」；清华博士后 张凯羿用 128 核虚拟 CPU、8 小时 22 分完成独立 Lean 验证；Lean 与 Mathlib 社区联合声明确认形式化证明通过核验、且所证命题的形式化表述确为黎曼猜想；OpenAI 一位数学研究员称「目前普遍认为这项证明是对的」。丘成桐「数学进入了一个新纪元」、梅纳德称 98% 或 99% 把握认为正确、陶哲轩称「巨大的 Lean-only proof」；三位数学家同时强调理解证明、提炼理论、提出新问题仍须人类完成。⚠️ 98%–99% 与「猫腻可能性约等于零」是数学家个人判断，按原话留档，不是本库结论。

同日对照：美国数学会主席、斯坦福教授 Ravi Vakil 紧急公布 Alessandro Maria Masullo 约 940 页纯人工 GRH 手稿《The Music of the Primes》（12 年、未用 AI、Brian Conrad 审读，原想再打磨 1 年）；公开约 8 小时后数人借不同 AI 模型发现疑点，整体策略是否成立尚无定论。同日 Alpöge 与 Buckmaster 又公布「即使没有外力，流体运动本身也可能产生奇点」的候选证明。此前千禧年七题只有庞加莱猜想（佩雷尔曼）正式列入已解决。

⚠️ 核实范围 / 口径边界：①「破解数学」是媒体简写 —— 722 篇无同行评审、部分被指错误，纳维–斯托克斯有优先权争议，三项进展均「仍待严格同行评审」，克雷说 NS「看起来已经解决」与「正式解决」是两件事；②「Claude 解决黎曼猜想」是标题简写 —— 准确是「人机合作候选证明 + Lean 形式化核验通过 + 多人独立编译」，未投稿 / 未评审 / 未领奖 / 未正式列入克雷已解决；③ 形式化核验通过 ≠ 数学界普遍接受，与 A038「仓库存在 ≠ 快照已核」、A036「核实成功也不全表升格」同属核实范围问题；④ 722 篇 / 4000 题 / 372 组结果是「手稿 / 尝试 / 出结果」三个计数，490 万条 / 3000 亿 token 与 270 万条 / 1300 亿 token 是「全程 / 该问题」两个范围，均不相加、不互相覆盖；⑤「≈付费版思考 3 小时」是自述等效口径，不写成成本规格；⑥ 日期 10-06 vs 10-07、11-20 北京时间 / 当地时间并列不调和。

边界与仍缺：本库没有下载 14 个压缩包、没有跑 Lean、没有读 25 万页论文、没有独立复算 1700 万行代码，也没有打开 722 篇手稿 / 166 页论文 / 940 页人工手稿；「通过核验」均为转述社区声明与学者独立编译。缺期刊评审结论与克雷研究所正式裁定（G46）。⚠️ 千禧年奖 100 万美元不代表本次已申领或颁发；OpenAI 9-08 明确放弃申领，两件事不合并。
