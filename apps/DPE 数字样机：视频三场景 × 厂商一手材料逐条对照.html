DPE 数字样机：视频三场景 × 厂商一手材料逐条对照

归类决定：归「CAD · AI 辅助设计」子栏目，不新建栏目。T010 的归集规则写得很明确「以后所有 CAD 相关的文章、视频、项目都归到这里」，本条是工业数字样机 / 装配设计 / 工程交付

页面可见信息（第五次空壳页）：短链 http://yb.woa.com/3x1QBfsbpa6 → channels.weixin.qq.com/finder-preview/pages/sph?id=AbzY5yPlDr，HTML 依旧只有 <title>视频号</title>。视频号名称、发布时间、地点、互动数字、封面 URL、字幕全部取不到 → 台账标 partial（内容待补）。用户给的是「@@DPE数字样机工具演示@@ + 视频内容总结 + 00:00–00:24 三场景时间轴」的模型总结式解析稿，不是带标准抬头的逐帧稿，按原样全量记、标「非逐帧取证」。

解析稿三场景全量（按原样，不润色）：① 00:00–00:09 复杂工业设备（类似自动化生产线或机械臂），屏幕显示「DPE数字样机」字样以及「模型管理」「装配设计」等功能按钮；随后画面快速切换，展示把一张简单的现场照片转化为「高还原度且可编辑的 3D 模型」；② 00:09–00:17 多个较小的机械部件（金属零件组合、带有线缆的圆柱形装置、绿色底座的仪器等）的 3D 建模过程，直观体现二维照片到三维模型的自动生成；③ 00:17–00:24 重点演示「四轴协同拧紧工作站」的数字样机效果，画面左侧出现性能指标图表、右侧是完整 3D 模型；随着操作者点击，模型中各零部件依次发生旋转、移动等动态变化，配合文字提示，展现该工具支持零代码配置动画、拆装演示和交互效果的强大能力。

一手交叉校验（仅用于标注偏差，不冒充视频画面）：厂商上海漂视网络股份有限公司（Shanghai Piaoshi Network Co., Ltd.）；DPE = Digital Prototype Editor，又称「DPE赋形」；官网 www.cimpro.cn / DPE 官网 dp.picimos.com / 产品体验 https://dp.picimos.com/ / 用户操作手册 https://dp-editor.picimos.com/manual.html；官方公众号「漂视数字孪生世界」「孪大师 CIMPro」「DPE数字样机研究站」的产品文、10-23 技术开放日回顾、SMT 贴片机案例；中华网 / CIOAge 关于接入 WorkBuddy 与 DeepSeek Harness 生态的报道。链接留 A029.leadUrl，不另建台账（G26）。

逐条对照（视频说法 / 一手口径 / 差在哪）：

  • 产品与厂商对得上：DPE 数字样机编辑器是上海漂视出品的 AI 原生 Web3D 数字样机与数字孪生开发平台；官方手册原句「DPE赋形是国产自研的 AI 原生 Web3D 数字样机与数字孪生开发平台，面向能源和智能制造」。视频没给厂商名，这里由一手补回，但不写成视频画面里出现过
  • 「照片 → 可编辑 3D 模型」对得上，但别夸大：官方叫「AI 图生 3D」——上传一张产品照 / 零件图 / 二维图纸，生成可编辑、可拆解、可交互的三维模型，自动归档进资源库。⚠️ 官方直播课明写「这里接的是 Tripo、Hyper3D 这类生成服务」，不是自研几何重建；视频说的「高还原度」是演示话术，官方口径只到「可编辑 / 可拆解」。这一层最容易把外挂能力写成自研内核
  • 「零代码配置动画、拆装演示和交互效果」对得上、但要拆开：一手是「事件→条件→动作」零代码交互系统 + 序列编辑器（时间线关键帧）+ AI 自动拆装序列（遮挡检测自动排定拆卸顺序、安装流程一键逆序、并行组号让同组螺栓同步旋出）+ 爆炸图 / 剖切 + 演示 / 培训 / 考核三模式只读播放器。不是「点一下就自动生成一切」，是官方把编排动作做成了可配置组件
  • 「模型管理」「装配设计」两个按钮名留白：官方界面截图里的页签是「大纲 / 创建 / 场景 / 历史 / 脚本 / 属性 / 交互 / 步骤 / 引导 / 相机 / 数据 / AI / 界面 / 工具 / 考核」与「资源 / 材质 / 模型库」，没有逐字命中这两个名称。按解析稿可见文字原样留，不校正、不补、也不冒充界面事实
  • 「四轴协同拧紧工作站」留白：这个具体设备名未在一手材料里单独命中（只见 OCR 碎片「__工作站」，不可靠）。按视频说法原样留，不补设备参数、轴数定义、拧紧工艺指标；官方公开案例是 SMT 贴片机 / 水轮机检修 / 99 式主战坦克图生 3D / 六轴机械臂 IK 示例，不是这一台
  • 左侧性能指标图表：数值一个都取不到。官方产品文里确有「动态数据看板集成贴装速度 CPH、贴装精度、良率、设备稼动率」这类描述，但视频里那张图表的具体数字、单位、口径全不可读 → 一律不补，见 T038 第三类
  • 演示话术要降级：「强大的功能」「直观体现」「支持……强大能力」是营销表述；所有效率数字（秒级出模 / 5 分钟模型到课件 / 3 分钟到可交付应用 / 15 至 27 倍）都是厂商自述，没有第三方实测，见 T066

转述链：厂商官网 / 手册 / 官方公众号 / 活动与案例 → 视频号演示画面（页面名取不到，不猜是不是官方「孪大师 CIMPro」视频号）→ 模型总结式解析稿（三场景）→ 用户提供 → 本库。比 A023 六跳少一层，因为这次视频里没有夹社媒评论截图、也没有转引一篇未署名报道。
