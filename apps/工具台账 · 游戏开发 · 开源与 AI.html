Godot

2D、3D、动画、物理全包；导出即商用，不抽成、不绑平台

— 作者：godotengine（A009 同源详版） · 平台：2D/3D 游戏引擎；桌面/移动/Web；一个安装包 · 开源：MIT · 11.8 万星（图卡）/ 十二万星（详版）

独立开发者的亲儿子；想做 2D 又不想被平台规则绑住基本是首选。⚠️ 两处星数口径不同，未调和，见 T020

Cocos（cocos2d-x）

一套代码多端发布，微信生态友好；API 成熟、教程遍地

— 作者：cocos2d（A009 同源详版） · 平台：国产跨端引擎；Web / iOS / 安卓 / 微信小游戏等 · 开源：近一万星 · 许可证原文未注明

发国内小游戏最顺，绕不开它；团队里谁都能快速接手。星数只写「近一万」，不精修

Phaser

网页 2D 小游戏框架，API 成熟、教程多

— 作者：phaserjs（A009 同源详版） · 平台：HTML5 / 浏览器直接跑 · 开源：4 万星 · 许可证原文未注明

HTML5 常青树，网页小游戏首选；很多人的第一行代码，打开网页就能玩最省事

PixiJS

专攻 Web 2D 渲染；做高品质互动、需要画面细节时比通用引擎更趁手
