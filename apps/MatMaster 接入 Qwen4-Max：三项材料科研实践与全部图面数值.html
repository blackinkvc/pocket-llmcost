MatMaster 接入 Qwen4-Max：三项材料科研实践与全部图面数值

公众号「阿里云」（user_name gh_df8e91cf9944），og:title《深势科技材料科研智能体 MatMaster 接入 Qwen4-Max》

按约定新建栏目「AI4S · 科研智能体」：主体是「把科研问题转成可执行计算流程」这一独立主题，横跨 Agent / 基模 / 实例，但既不属于 AI Infra 的商业公司分层，也不是学习路线或企业知识库选型，故独立成栏；related 挂 agent / model / case / skill。

正文文字全量整理（共 11 段 + 3 条图注 + 文末活动信息）：

  • 开头：近日深势科技玻尔科学空间推出的材料科研智能体 MatMaster 接入 Qwen4-Max，围绕晶体缺陷计算、团簇生长模拟和光纤分析开展科研实践；三项任务展示模型把科研问题转化为可执行计算流程的能力，也为后续实验验证与材料设计提供计算参考
  • 深势科技定位：全球 AI for Science（AI4S）领域的开拓者，致力于 AI 科学家的研发与应用。MatMaster 在玻尔科学空间推出，为材料研究提供专业知识、工具链和计算资源支持，并留存代码、参数、图表及运行记录；研究人员可据此检查计算过程、调整研究条件、在已有结果上继续研究
  • Qwen4-Max 定位：阿里巴巴发布的新一代基座大模型，具备原生视觉能力、支持百万级上下文，重点增强智能体、编程和专业工具调用能力，并针对长周期、复杂约束的真实工作任务做了优化
  • 评测说明：在深势科技内部科学评测中，Qwen4-Max 在材料科学任务中表现良好；深势依托科研任务、数据与科学工具积累及玻尔科研基础设施开展评测，通过独立验证器核查科学结果与任务完成情况，并结合运行记录追溯偏差，为模型团队提供改进线索。此次接入把模型能力与 MatMaster 的专业工具及计算环境结合，应用到具体材料科研场景
  • 任务一 晶体缺陷：Qwen4-Max 根据十组材料参数编写计算程序，比较 FCC 金属中完整螺位错解离为两条 Shockley 部分位错后的平衡间距；体现把物理问题转成参数化计算、组织数值求解与核对的能力。正文明确留了边界：铂的预测宽度已处于原子尺度，实际位错核心仍需原子模拟或实验验证
  • 任务二 团簇生长：研究问题「在给定晶格生长模型下，改变单体能够形成的连接数会怎样影响团簇形态」；转成生长模拟与分析程序，用 MatMaster 计算工具比较四组配方；考虑随机性，每组重复 100 次、共 400 次模拟、每个团簇 5 万个单体、总用时 46.6 分钟；后续复核中研究人员根据运行记录恢复代码、用原随机种子复算，四个指数均复现至原报告精度
  • 任务三 非同心双芯光纤：需从多个相近计算结果中识别原有的三个光传播模式，确保结构变化前后比较的是同一模式；为改善求解稳定性，模型调整了方程的求解形式，再依据光场分布追踪模式对应关系，借助 MatMaster 完成计算；后续针对原运行选定解中的一个模式复算光场剖面，确认两个相反方向上的峰值与原运行结果一致
  • 结论：从参数化计算、重复模拟到求解调整与模式追踪，三项任务展示 Qwen4-Max 与 MatMaster 协同开展材料计算与分析的能力，为位错解离定量对照、配方筛选和光纤设计比较提供计算参考
  • 未来：MatMaster 将继续与 Qwen 模型协同探索 AI4S，让研究人员把更多精力投入关键科研判断与后续验证
  • 文末：12 月 2-3 日上海阿里云 AI Coding 嘉年华——深势科技将分享「从 AI Coding 到 AI 科学家」；/ END /
