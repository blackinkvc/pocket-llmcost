36 万星 · 10 个可商用开源游戏项目：三条硬标准、完整清单与选型对号入座

公众号「兰心运营笔记」（作者自称「兰心」），发布于 2026-11-17 17:48，栏目标注 GAME DEV · 工具盘点 2026.11。

作者先给三条硬标准，只有全过才进名单（这部分只在同源详版文字里，图片卡没有）：① 许可证清晰——license 含糊的，商用就是给自己埋雷；② 半年内有提交——半年没人提交的大概率凉了；③ 社区够大——社区太小，遇到问题连个能搜到的答案都没有。排序原则也特意说明：按上手价值排，不看星标，「星标高不等于你今晚能用它做出东西」。

⚠️ 取证说明：用户给的链接是图片版，21 张正文原图（去重 12 组）逐张读完，只有 7 张项目精修卡：1 Godot、2 Cocos、3 Phaser、4 PixiJS、6 raylib、9 Unity MCP、10 Game Dev Agent Skills；第 5 / 7 / 8 项没有独立详情卡。这三项的星数、仓库地址与定位，依据可检索到的同源同文详版（同为「兰心运营笔记」、同一标题、GAME DEV 2026.11）补全，并在台账标了来源性质。图卡上被打了马赛克/像素化的数字（Unity MCP、Agent Skills 卡左侧的星数位置）按详版填，不猜。

10 个项目完整清单（星数按各来源原样记录，不做调和）：

  • ① Godot — 11.8 万星 / 十二万星（图卡/详版口径不一），MIT 许可，godotengine/godot。独立开发者的亲儿子，不抽成、不绑平台、导出即商用；2D/3D/动画/物理全包，一个安装包打开就能干。想做 2D 又不想被平台规则绑住，基本是首选
  • ② Cocos — 近一万星，cocos2d/cocos2d-x。国产跨端引擎，微信生态友好，一套代码发 Web / iOS / 安卓 / 各种小游戏；API 成熟、教程遍地，国内小游戏渠道跑得最溜
  • ③ Phaser — 4 万星，phaserjs/phaser。HTML5 2D 常青树，网页小游戏首选；浏览器直接跑，教程多到挑花眼，很多人的第一行代码
  • ④ PixiJS — 4.8 万星，pixijs/pixijs。Web 顶级 2D 渲染器，精灵/粒子/滤镜全有、性能强劲；专攻 Web 2D 渲染，做高品质互动和画面细节比通用引擎趁手
  • ⑤ Babylon.js — 2.6 万星，BabylonJS/Babylon.js，微软维护的 Web3D 引擎。PBR、物理、粒子系统齐全，浏览器里也能跑出电影级画面；搞网页 3D 绕不开的一站（图卡缺失，据同源详版补全）
  • ⑥ Bevy — 4.9 万星，bevyengine/bevy。Rust 写的数据驱动 ECS 引擎，性能上限高、适合硬核团队认真啃 3D；代价是 Rust 学习曲线，入门没前面几个轻松（图卡缺失，据同源详版补全）
  • ⑦ raylib — 3.5 万星，raysan5/raylib。C 语言、零依赖、一个压缩包开工，没有黑盒魔法、源码摊在那儿；想搞明白游戏循环和渲染怎么跑，学底层特别合适，桌面/移动/Web 通吃（图卡标为第 6 项）
  • ⑧ libGDX — 2.5 万星，libgdx/libgdx。Java 跨平台老将，桌面/安卓/iOS/Web 一套代码铺开；Java 生态稳、文档全、老项目多，团队 Java 底子厚几乎不用重新招人（图卡缺失，据同源详版补全）
  • ⑨ Unity MCP — 1.6 万星，CoplayDev/unity-mcp。让 Claude 和 Cursor 直接操作 Unity：建对象、连组件、写脚本，一句话说完就帮你做完；关键是只在自己项目里开，权限握在自己手上，不用把代码传到别处 → 详见 T021
  • ⑩ Game Dev Agent Skills — 9.2 千星，gamedev-skills/awesome-gamedev-agent-skills。74 个技能包，覆盖 Godot、Unity、Unreal 三大引擎，装进 AI 工具等于请了个随叫随到的游戏导师 → 详见 T022

作者的选型对号入座（文末一段，直接可抄）：网页 2D 首选 Phaser，要渲染细节上 PixiJS；国内小游戏用 Cocos，独立做 2D 或 3D 上 Godot；想玩 Web3D 选 Babylon.js，硬核 3D 团队看 Bevy；学底层摸 raylib，Java 团队用 libGDX。压轴那两个装上，等于给上面所有引擎配了个 AI 搭档。

文末态度：做游戏最贵的不是引擎，是你一直不开始——「先收藏，挑一个，今晚做一个能玩的原型」。作者自述分享 AI、互联网、创业、副业、职场规划等思路。
