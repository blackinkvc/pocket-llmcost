⑤ 正文完全没写、只在图里的结果数值（A017 新增，也是最容易被漏掉的一类）：MatMaster 那篇正文只给了「十组参数 / 400 次模拟 / 46.6 分钟」等汇总数字，但八种 FCC 金属位错宽度的具体 Å 值、四组配方比例、双芯光纤的几何与折射率参数、三个模式的折射率增量全部只存在于配图中，图注也只解释口径不给数值。这类数值既不是演示也不是示意，是文章声称的计算结果，但正文本身没复述——所以逐张读图不是可选项，漏了就等于漏掉一半结论。标注方式：写清「来源＝图面 / 正文未载 / 未外部复核」，与①②类一样不能当已验证的性能指标。

⑥ 转述中被改变了语义的数值（A018 新增，最该警惕的一类）：视频描述把「LOCKER 求解矩阵的所需内存从 42PB 降到 58MB」写成了「把 42PB 的天文级数据压缩到 58MB」——数字分毫不差，性质完全变了：前者是代数结构优化（转置系数矩阵、解锁偏 Frobenius 映射）让一个原本建不出来的矩阵变得可建，后者听起来像违反信息论下限的通用压缩术。同一视频还把「TII McEliece 挑战 94 个实例里 55 个首次有解」揉进「攻破 NIST 后量子候选、55 道人类从未解开的难题」，把两类不同目标混成一句。处理方式：不靠数量级直觉判定真假，也不照抄转述，而去找一手来源把口径校正回来，并把「转述写法 / 一手口径 / 差在哪」三者并列留档。见 T041 / T042。

⑦ 自动解析稿里的专名 / 数字 / 语义三类错乱（A020 新增，是一整层转述而非某一个数字）：带时间轴的「视频解析内容」已经是机器转述，这次一篇里三类齐发 —— 专名（MemmTensor→MemTensor、MemmT-AgentBench→MemoryAgentBench）、字符数字（23.67→23.87、S5.08→53.08）、语义（「经验写入提供持续微调」实为冻结主干只更新运行时状态；「13M 内部记忆」实为动态记忆状态大小）。与前六类的区别：⑥ 是某一个数字被改了语义，⑦ 是整层转述把专名、数字、语义一起漂了，且常常「页面可见标题反而比解析稿更严谨」。处理方式：解析稿按原样全量记录并标「非逐帧取证」，再三类都回一手核对，把「转述写法 / 一手口径 / 差在哪」三者并列留档；查不到的标「来源不明 / 疑似 OCR」，不删也不补。见 T044 / T046。

沉淀成规则（并入维护约定）：以后资料里出现数字，整理稿必须同时写清 数值 + 属于哪一类 + 是否核实；速查表评价里带 ⚠️；演示 / 示意 / 估算值一律不写成性能指标或效果证据；同一数字的多种约数并列不调和；遇到「看起来不可能」的数字，先找一手来源查是不是语义错置，别急着标假或照抄；遇到自动解析稿，专名 / 数字 / 语义三类都要回一手核对，不能只查数字。与 T032（整篇证据等级）、T040（官宣 / 内部评测）、T042（公开 PoC 与转述链）、T046（自动解析稿证据等级）、T016/T023（口径冲突与取证记录）合起来，构成本库对「资料可信度」的六层标注。
