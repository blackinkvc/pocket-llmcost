2026-11-24 · 开源 · 定价 · 商业模式

开源把价格打到地板，然后开始收费

中国开源模型下载占比首次超过美国，开源与闭源的 token 价格差到五倍。但「开放权重」不等于开源，免费也正在变成有条件的：年收入过两千万美元，就要单独签约。

一句判断：开源做的不是「让能力免费」，是「让能力没有溢价」。

这两件事的差别，决定了谁能活下来。能力被打平之后，钱会流向两个地方：把能力装进具体流程的人，和替别人承担风险的人。

先把规模说清楚

Hugging Face《2026 年春季全球开源 AI 生态报告》里，中国开源模型的下载占比达到 41%，首次超过美国，累计下载量突破 100 亿次。Qwen 在全球开源模型的采用率约 53%，Llama 降到 15%，Gemma 14%。阿里累计开源 460 多个 Qwen 模型，下载 30 亿次，衍生模型超过 30 万个。

这些数字说的是「分发」，不是「能力」。一个模型被下载一百万次，不代表它被用在生产环境里；但分发到这个量级，意味着任何一个做应用的人，都有了一个免费或者极便宜的底座选项。

价格：差一个数量级，但两边在反向走

Silicon Data 的 token 支出指数给了一个干净的对照：闭源模型约 3.07 美元／百万 token，开源约 0.66 美元，差近五倍；综合指数在 2026 年首次跌破 1 美元。第三方评测里，DeepSeek V4-Pro 的输出价约 0.87 美元／百万 token，Grok 4.6 是 6 美元，差七倍，而两者在 Terminal Bench 上的分差只有 0.1。

但 2026 年的走势不是单向降价，而是两条线反向走：

口径变化说明
闭源 API持续降价OpenAI、Google 之间的价格战
开源模型实际使用成本从 0.66 美元/百万 token 上行不是提价，是用的人和场景变多，总账单变高
中国大模型平均 API 价2026Q2 输入 4.9 元、输出 21.9 元比 2025Q1 的 3.3 / 12.2 元涨 48% / 80%
第三方托管推理同一款模型最低报价约为官方低谷价的 1/4数十家服务商在同一个权重上打价格战

最后一行是关键：权重开放之后，推理服务变成了一个可以批发的商品。 原厂可以把 API 价格往上抬，托管商立刻用更低的报价把流量接走。厂商的定价权从「模型多强」转移到「谁的服务更稳、更合规、更便宜」。

「开源」这个词正在缩水

需要说清三件事：

  • 开放权重不是开源。 Llama、Qwen、DeepSeek 多数只公开训练好的参数，训练代码和数据集不公开。按严格标准，2025 年之后符合基本开源定义的「开源模型」不到四成。
  • 许可是有条件的。 Kimi K3 的许可规定：连续 12 个月总收入超过 2000 万美元的 MaaS 提供商需要单独签约，分成最高 30%。Qwen3.8-Max 也在讨论类似的收益分成。免费的是小用户，不是大生意的转售权。
  • 透明度在下降。 追踪模型开放程度的指数从 58 掉到 40，训练数据、参数量、算力的披露都在减少。能力越来越强，可读性越来越差。

对行业意味着什么

开源压掉的不是「软件的价格」，是「能力作为商品」的价格。一件东西一旦有免费的同级替代，它就只能靠三样东西收钱：

  1. 集成——把它接进具体业务的那部分工作量，仍然要人做；
  2. 责任——出错了谁赔、数据放哪、能不能过审计；
  3. 分发——用户已经在你的入口里，换一个要多走三步。

这也解释了为什么 2026 年最赚钱的 AI 产品大多不是模型：模型层的价格被开源按住，应用层可以用近乎零的边际成本去试错，而真正的护城河退到了流程、数据和责任上。

已知的取舍

  • 下载量不等于使用量。 41%、53%、100 亿次都是分发口径，Hugging Face 自己也区分不了下载是跑起来了还是放进了收藏夹。
  • 价格指数是加权结果。 开源综合成本上行，一部分来自用量结构变化（长上下文、多模态、Agent 多轮），不能直接读成「开源变贵了」。
  • 一个模型在榜上强，不代表工程上稳。 评测分数与真实业务里的可用性之间，隔着上下文管理、工具调用稳定性和失败重试，这些没有公开基准。
  • 本页不预测价格。 这个市场的价格以周为单位变动，写死数字一个月就会错。
