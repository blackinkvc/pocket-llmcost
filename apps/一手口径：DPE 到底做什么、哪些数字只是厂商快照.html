一手口径：DPE 到底做什么、哪些数字只是厂商快照

⚠️ 本卡全部来自厂商官网 / 用户手册 / 官方公众号与活动回顾 / 媒体转述，不是视频画面，也不是第三方评测。单列一卡是为了把「视频演示了什么」与「产品文档写了什么」分开。

产品定位：DPE 数字样机编辑器（DPE赋形），上海漂视网络股份有限公司出品；B/S 架构、纯国产自研 Web3D 内核，浏览器即开即用、免安装、跨 Windows / macOS / Linux 与国产桌面；官方称全栈信创适配（海光 / 飞腾 / 鲲鹏 CPU，摩尔线程 / 砺算 / 象帝先 GPU，麒麟 / 统信 OS 与国产浏览器），面向智能制造、轨道交通、船舶海洋、能源电力、教育培训与孪生集成。课件以链接 / 工程包分发，学员端零安装，微信里点开即可学。⚠️ 商业授权、流程商业授权，不是开源；公开渠道只给 7 天或 15 天免费试用。

五组能力（按官方产品文与手册）：

  • 多源模型接入：STP 工业装配体原生拖入浏览器，端侧解析与三角化，装配层级与构件命名原样保留、自动生成大纲树；高斯点云 / LCC2 实景导入（千万级点云流式加载，界面示例 491.2 万点 SPLAT 文件 149.9MB），支持与 BIM / 工业模型同场景坐标配准叠加；AI 图生 3D（照片 / 二维图纸 → 可编辑可拆解三维模型，官方直播课注明接 Tripo / Hyper3D 类生成服务，界面有「目标面数 30000」「PBR 贴图」配置项）
  • 编辑与工程检查：PBR 材质编辑器 82 种预设、材质吸管；一键智能爆炸图；基于自研流形布尔引擎的平面 / 盒式剖切；手册明写「碰撞与干涉检查」工作台，可选实体重叠 / 静态净距 / 边界接触，净距用米且「须有项目依据」，接触策略「允许」只处理边界接触、不允许材料侵入；并写「分析不降低源面数，也不改源模型材质、变换或层级」——这是手册里少见的工程边界句，按原样收
  • 拆装与课件：批量生成步骤、并行组号、遮挡检测自动排序 + 安装一键逆序、相机机位录制、序列编辑器（时间线关键帧）；零代码交互系统「事件→条件→动作」；AI 自动编排讲解点与考核点；演示 / 培训 / 考核三模式只读播放器（学员只能看流程与参与考核、改不了内容，考核自动评分）；发布形态——A 文写「Web 课件包 / .vtcourse 课件数据包 / AES 加密独立 exe / 云端串流链接」，B 文写「.vtpack 工程包 / 在线链接 / 培训视频 / iframe 嵌入」，两种口径并列、不调和
  • AI 助手与智能体接入：对话式改材质 / 灯光 / 相机 / 动画 / 拆装 / 标签弹窗，AI 自动搭业务页面（图表 + 按钮 + 数据绑定一次生成）；开放 API / SDK / MCP，官方称支持任意大模型（在线或私有化）直接操控编辑器；已接入 WorkBuddy 智能体（DPE 作为「专家」+ 封装 Skill）与 DeepSeek Harness（DSH） 插件体系；与 CIMPro孪大师 数字孪生平台工程互通，数字样机直接作为孪生场景设备资产，一次建模多处复用
  • 公开案例与活动：10-23 上海「DPE 数字样机技术开放日」（议程含高斯点云 LCC 实景导入、AI 图生 3D、Codex 内部能力接入演示、STP 原生导入、工程爆炸图、AI 智能拆装、POI 零代码交互、一键导入 CIMPro孪大师、WorkBuddy 接入 DPE）；9-21「孪大师 CIMPro」视频号直播；11-27 上海·闵行 DPE赋形技术开放日（蒸汽发电机数字样机）；工博会与温州制造行业沙龙；SMT 贴片机数字样机案例（整机概览 / 结构拆解 / 贴装工艺 / 操作实训四页，已脱敏转成模板 Demo）、水轮机检修蓝图、99 式主战坦克图生 3D、六轴机械臂 IK 示例

⚠️ 数字口径并列留档（全部厂商自述 / 不同时期界面快照，按 T038 第三类标「不是实测」）：

  • 版本号：V7.9.150（多篇界面截图）/ V7.9.159（产品文写「平台当前版本」）/ V7.9.110（SMT 案例截图）——三种并存，不调和、不判断哪个最新
  • 开放能力数：「969 项 API 能力，全量 API 经 MCP 协议与 Skill 对外开放」/「开放 393 项 API 接口」/ 界面「调用 413 个软件能力」——三处数字不一致，按各自出处并列
  • 效率与性能：「秒级出模」「5 分钟跑通模型到课件」「3 分钟从 3D 模型到可交付应用」「传统数周压缩至小时级」「SDK 直嵌高频调用性能提升 15 至 27 倍」——无测试条件、硬件、基线，不写成性能结论
  • 规模与界面监视值：千万级点云 / 491.2 万点 / 82 种预设材质 / 目标面数 30000 / 「FPS 79·内存 993MB·构件 2·三角面 407.3k」与「FPS 120·内存 423MB·构件 28·三角面 407.3k·顶点 1222k」——是运行截图里的示意值，不是基准测试

⚠️ 必须补回的边界：① 以上全部是发布方自述与官方活动 / 脱敏案例，缺第三方独立评测、真实客户名单与工程验收标准；② 图生 3D 接外部生成服务，不等于自研几何内核；③ 商业授权 ≠ 开源，试用 ≠ 可复现，API / MCP 清单全文未公开；④ 案例已脱敏，不能当已落地项目的量化效果；⑤ 「5 分钟 / 秒级 / 15–27 倍」这类数字没有对照口径，别引用成效率结论。

一句话：DPE 不是「照片变 3D 的魔法」，是把存量 CAD / 点云资产接进浏览器，再用零代码组件把拆装、动画、讲解、考核编排成可交付课件的工程链路产品；AI 图生 3D 是入口之一，不是全部。
