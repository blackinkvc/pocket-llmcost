Unity MCP：把 MCP 从「连工具」推到「直接操作游戏引擎」

A009 的压轴项目之一。与 T004（连接层三件套：代码索引 / MCP-ACP 协议 / 沙盒）同板块但主题不同——T004 讲协议在 AI Coding 架构里的位置

能做什么：让 Claude 和 Cursor 直接操作 Unity，建对象、连组件、写脚本，「一句话说完就帮你做完」。图卡上的原话是「AI 操作 Unity｜一句话完成开发」，画面里是 Unity 编辑器与 AI 对话框连线的示意。

权限边界是它最值得记的一点：只在自己的项目里开，权限握在自己手上，不用把代码传到别处。这和 T004 里「协议管连接与访问权、沙盒管隔离」是同一条思路，只是落到了游戏引擎上——也和 T007 / T009 反复出现的「Agent 得能看见自己做出来的东西」呼应。

与 CAD-MCP（T008）的对照：两者都是把 MCP 接进一个重客户端（AutoCAD / 浩辰 / 中望 ↔ Unity），都强调本地连接与截图/句柄回读；差别是 CAD-MCP 停二维绘图，Unity MCP 面向完整 3D 工程与脚本。后续若收到更多「MCP + 具体软件」的资料，相近内容并入本卡，不同软件并列补要点。

整理说明：星数 1.6 万、仓库 CoplayDev/unity-mcp 与权限说明来自同源详版文字；用户所给图片版的这张卡左侧星数位置被打码，按详版填，未猜。
