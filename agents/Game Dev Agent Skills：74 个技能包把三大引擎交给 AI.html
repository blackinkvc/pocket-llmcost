Game Dev Agent Skills：74 个技能包把三大引擎交给 AI

A009 的最后一个项目，也是标题里「最后一个 AI 直接帮你做游戏」指的那个。图卡标注「74 个技能包｜AI 游戏导师」，右上角小窗写「74 游戏原型快速快速生成」（图面重复字，按原样保留）

同源详版补充：仓库 gamedev-skills/awesome-gamedev-agent-skills，9.2 千星，74 个技能包覆盖 Godot、Unity、Unreal 三大引擎；装进你的 AI 工具里，等于请了个随叫随到的游戏导师，卡在哪一步直接问它。作者把它和 Unity MCP 一起列为「把工具交给 AI，让它替你动手」的压轴两个。

与同板块其他卡的关系（故并列、不合并）：T001/T002 讲单个 Skill 的输入输出契约与设计原则；T008 是 CAD 领域六个开源项目横评；T015 是 WorkBuddy 办公场景 30 个 Skill 清单；T013 是知识图谱类 Skill。本卡是游戏开发垂直领域的技能包合集，触发场景、交付物与前三组都不同。

可迁移判断：一个技能包合集值不值得装，看它是否覆盖你已在用的引擎、是否按「卡在哪一步」组织，而不是只看技能数量。74 这个数字之所以有用，是因为它对应三大引擎的完整工作流，不是堆数量。

整理说明：「游戏原型快速生成」是图卡小窗里的字样；仓库与覆盖引擎来自同源详版文字，已标注来源性质。
