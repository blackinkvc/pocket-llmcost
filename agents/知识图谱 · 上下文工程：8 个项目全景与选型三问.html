知识图谱 / 上下文工程：8 个项目全景与选型三问

A005 是一篇几乎全部信息都在图片里的文章（正文 23 张图，去重后 15 组）。主题：写代码或做内容，都有必要建「知识图谱」。公众号「AI 经纬线 · 知识图谱专题」，图上标注 2026.08.29

总览图给的关键数字：TOTAL 38.0万★ · 8 PROJECTS；顶部三句卖点「评审省 71× token（CRG 实测）· 改码前先看爆炸半径 · 通过率 +51%（TencentDB）」。8 个项目按形态分：SKILL ×3、MCP ×4、WEB ×1、CLI ×1。

  • 01 graphify（SKILL / Python / Apache-2.0 / 112.1k★）：代码、PDF、截图、白板照片全进同一张图，不依赖向量库；标签 #多源混合 #非代码资料 #长期沉淀
  • 02 Understand-Anything（SKILL / TypeScript / MIT / 80.9k★）：双视图 + 引导式导览，按依赖顺序带你把陌生仓库读一遍；#接手陌生仓库 #新人上手 #业务视角
  • 03 GitNexus（WEB / TypeScript / 非商用 / 46.2k★）：浏览器内 WASM 建图，代码不出本机，17 个 MCP 工具可用；#临时看别人的库 #代码不出本机 #零安装
  • 04 codebase-memory-mcp（MCP / C / MIT / 41.0k★）：纯 C 单文件二进制，Linux 内核 28M 行 3 分钟建完图；#超大仓库 #亚毫秒查询 #多语言
  • 05 code-review-graph（MCP / Python / MIT / 31.0k★）：增量建图，评审时只喂该读的上下文，实测省 71 倍 token；#代码评审 #省 token #增量更新
  • 06 archify（SKILL / JavaScript / MIT / 28.8k★）：代码库先转成类型化 JSON，验证器校验通过才渲染成架构图，模型幻觉会被拦下；#架构变更评审 #可验证输出 #对外讲结构
  • 07 TencentDB-Agent-Memory（MCP / TypeScript / MIT / 25.1k★）：团队级记忆中枢，代码图是四类可复用记忆资产之一；#团队共享记忆 #长会话 #跨 Agent
  • 08 openwiki（CLI / TypeScript / MIT / 15.8k★）：会自己维护的 Wiki，每条事实都钉着版本化的源码证据；#文档自动维护 #事实溯源 #对外展示

图里第 09 格是选型方法，比工具清单更值钱——先回答三个问题再挑工具：① 代码能出库吗？② 团队要共享索引吗？③ 读图的是人还是 Agent？答完这三个，8 个项目基本只剩 1–2 个可选。

场景对号入座（图底 CODING / WRITING 分区）：写代码 → ①代码文档全建图、②接手项目、③快速看库、④日常编程、⑤评审、⑥架构图；做内容 → ①素材进图、⑧知识库自维护、⑥画流程图关系图；两样都沾 → ⑦团队记忆。底部另有六个标签：#接手旧系统 #重构评审 #线上排障 #素材进图 #知识自维护 #团队记忆。

整理说明：星数、形态、语言、许可、仓库全名均按图面原样记录，未与 A006 中同名项目的不同数字做调和；差异见 T016。图面 8 个项目但只有 7 张详情卡，archify 无独立详情页，已如实标注。
