Tree-sitter / LSP

像超级目录，秒级定位代码

— 平台：代码索引层

上下文工程的地基，给 Agent 装「眼睛」

MCP / ACP 协议

像万能插座，统一接入外部工具与数据源

— 平台：外部工具连接层

管连接与访问权，不负责推理；说明连接标准不止一家

E2B / Docker

防爆实验间：代码跑崩也不伤及真系统

— 平台：隔离运行时 / 沙盒

让 Agent 敢跑、敢失败、敢重试

UHP / HarnessRouter（Unified Harness Protocol）

三个价值：一次接入（上层只对接一套接口）、多 Harness 复用、更易扩展（新增 Harness 不必重写整套后端）。

— 平台：产品后端 → UHP / HarnessRouter → Codex /
