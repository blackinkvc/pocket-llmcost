Epochal / 时光门户：视频六场景 × 一手口径逐条对照

归类决定：归「Agent」栏目（规划与推理 / 评测与失败模式），不新建栏目。Time Portal 的主体是「给智能体造一个防剧透的历史回放评测环境」

页面可见信息（第四次空壳页）：短链 http://yb.woa.com/4AK3r0d8UHO → channels.weixin.qq.com/finder-preview/pages/sph?id=AERoJnSxGr，HTML 依旧只有 <title>视频号</title>。视频号名称、发布时间、地点、互动数字、封面 URL、字幕全部取不到 → 台账标 partial（内容待补）。用户给的是「【视频解析内容-模型总结信息】+ 00:00–02:29 时间轴」自动解析稿，按原样全量记、标「非逐帧取证」。

解析稿六场景全量（按原样，不润色）：① 00:00–00:19 Epochal Logo + 创始人张国栋照片，「离开马斯克后，这位中国人自掏腰包投资 1 亿美元，在硅谷创办了名为 Epochal 的 AI 公司」，产品叫「时光门户」；② 00:19–00:47 带锁的门变成书本和日历，讲最大难点是「剧透」——现在的 AI 熟知过去所有信息，所以收录过去 30 年超过 1 万亿个网页，把 AI「锁死在过去某一时刻」，只能检索当时互联网；③ 00:47–01:12 新闻 / 财报 / 市场数据图标 + 时钟拨到 2008 年，说「如果把时间拨回 2008 年金融危机爆发前夕，AI 必须仅凭当时线索判断未来走向，再用真实历史结果打分」；④ 01:12–01:45 三位创始人：毕业于浙大的张国栋（曾负责 Grak Code）、清华毕业的戴子航（曾参与大模型研究）、曾在 DeepMind 工作过的 Manuel Kroiss（主导过 xAI 预训练团队），称均来自 xAI 元老，今年 2 月 SpaceX 收购 xAI 后陆续离职，拉上 OpenAI / Anthropic / Google DeepMind 前员工另起炉灶；⑤ 01:45–02:19 命令行工具、Rust 与 Python 客户端、AI 智能体 + MCP 服务器架构图，称同步上线并开放 MCP 服务器，下一步做辅助决策的前沿大模型，官网写「衡量智能的最佳标准，是预测未来的能力」；⑥ 02:19–02:29 「如果你能……预测未来」，邀请评论区留言最想预测什么。

一手交叉校验（仅用于标注偏差，不冒充视频画面）：Epochal 官方公告《Introducing Time Portal》与工程文档（2026-11-24）、Bloomberg 报道（经 The Next Web / 财联社 / 腾讯新闻 / Quartz / Unite.AI / The Rundown AI 等转述）、MIT CS3 无关、Epochal 定价页与 API 文档。链接留 A024.leadUrl，不另建台账（G23）。

逐条对照（视频说法 / 一手口径 / 差在哪）：

  • 公司对得上：Epochal 于当地时间 2026-11-24 正式亮相，首款产品 Epochal Time Portal（时光门户 / 时间传送门），CEO 张国栋 Guodong Zhang；官网原句「衡量智能的最佳标准，是预测未来的能力」「Today's AI has read almost everything and lived through almost nothing」「超人类水平的预测将重塑几乎所有行业，因为每一个决策都是一次预测」——视频那句引言属实
  • 1 亿美元要降级：一手是 Bloomberg 援引匿名知情人士称张国栋个人投入 1 亿美元，Epochal 官方拒绝置评、无其他投资方披露。视频写成「自掏腰包投资」的确定事实；另有中文号写「完成 1 亿美元融资」，两种转述并存，本库按一手口径标「单源未证实」
  • 规模对得上但漏了一半：一手为「>1 万亿存档页面、追踪 >7 万亿 URL、30+ 年历史、热门页版本粒度精确到分钟、90 天建成」，视频只给了 1 万亿 / 30 年。这些都是厂商自述口径，无第三方核验
  • 「锁死在过去」讲浅了：一手是 search / fetch / sandbox 三 API + Accept-Datetime 头；fetch 只返回 ≤ 指定时刻的最新快照，取不到就报错、绝不拿更晚的副本替代；Linux 微虚拟机的系统时钟、Ubuntu 镜像、apt / pip / uv / npm 软件源与全部出站流量都冻结在同一日期。视频只说了「网页检索」，没提沙箱环境这一层
  • 2008 年金融危机是视频自举例，不是官方实验：一手公开的预设示例是「1995 年底问『电脑能否击败最强人类棋手』→ 回答『还没有』；拨到 1997 年 5 月 → 『可以』」。正式自测是 347 道 Kalshi / Polymarket 实时预测题：先在结果揭晓前实时预测，数周后把截至时刻调回原始预测时间回放，比较两次误差——Time Portal 回放与原始实时误差相关性 0.98，用揭晓后实时网页 0.16，完全不联网 0.49。⚠️ 0.98 量的是环境还原度（回放像不像当初），不是预测准确率；题目清单、误差分布、独立泄漏审计均未公开，公司也没公布预测准确率
  • 团队基本对得上，两处要留白：三位 xAI 创始成员张国栋、戴子航 Zihang Dai、Manuel Kroiss 属实；官方公告还列了 Alex Bocharoff、Frank Luan 两位；团队含 OpenAI / Anthropic / Google DeepMind 前员工属实。张国栋此前在 xAI 直接向马斯克汇报、负责 Grok Code（视频写「Grak Code」是拼写错）；Kroiss 负责预训练、曾有 DeepMind 背景。「张国栋毕业于浙大 / 戴子航毕业于清华」在检索到的权威源里未逐人确认，按视频说法原样留、不采信为事实。2026-02-02 SpaceX 全股票收购 xAI（合并估值 1.25 万亿美元、xAI 2500 亿），三人 3 月前后离职；到 3 月底 11 位非马斯克联合创始人全部出清，视频「2 月后陆续离职」方向对但简化了
  • 工具链对得上：命令行工具、Python / Rust SDK、控制台 playground、MCP 服务器、下一步做辅助决策的前沿模型——均见一手报道。免费额度极有限（每组织 100 次 search+fetch、1 小时 1vCPU/2GiB 沙箱，付费需联系销售），视频没提

⚠️ 必须主动补回的边界：① 1 万亿网页如何采集、是否取得授权，公司未披露（数字存档行业法律灰区）；② 0.98 是内部自测、保真度口径，不是「AI 预测更准」；③ 外部请求冻结了，但基座模型权重里的参数化泄漏（parametric leakage）堵不住——智能体可能本来就记得历史结局；④ 没有自研模型发布时间表、没有独立评测、没有完整定价；⑤ 真正该等的是「在模型训练截止日之后才揭晓的题目上、带公开题单的准确率」。见 T059 / T060。

⚠️ 未给 / 不补：视频号名称与时间、逐帧画面与字幕、Epochal 官网与工程文档全文、Bloomberg 原文、347 道题清单与误差表、归档数据来源与授权、第三方复现、真实预测准确率。二手解读里另出现「每日抓取 100 亿页」「UCSD ACL 2026 论文 71%/81% 泄漏」「Kalshi 月交易额 1100 亿美元」等数字，未在一手摘要里核实，本库不引入。
