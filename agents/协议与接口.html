协议为什么比模型更影响生态

2024 到 2025 年，Agent 生态最大的变化不是模型，而是接口开始标准化：MCP 管纵向接入，A2A 管横向协作，AGENTS.md 管仓库里的约定。

2024 到 2025 年，Agent 生态最大的变化不是模型，而是接口开始标准化。

协议提出方时间解决什么状态
MCPAnthropic2024-11模型 / 客户端如何统一接入外部工具与数据源事实标准
A2AGoogle2025-04不同厂商的 Agent 之间如何发现与协作推进中
AGENTS.md社区 / 多家2025把仓库里的操作约定写给编码 Agent 看约定俗成

MCP 是「纵向」接口：Agent 往下接工具。A2A 是「横向」接口：Agent 之间互相调用。 两者不冲突，但成熟度差一截——MCP 已经有成千上万个现成服务器，A2A 还停在「有规范、没生态」。

为什么协议重要

工具方接入一次，就能被所有支持该协议的客户端使用。协议稳定之前，每接一个客户端都要重写一遍适配层， 成本高到没人愿意做；协议稳定之后，工具方才开始批量入场。

这也是 MCP 服务器数量在 2025 年暴涨的直接原因。

看协议成熟度看什么

  • 有没有参考实现：只有文档没有 SDK，等于没有
  • 鉴权怎么做：能不能细到单个工具、单个用户的权限
  • 错误怎么传：工具失败时返回什么，决定了 Agent 能不能自我纠错
  • 版本怎么演进：破坏性变更会不会把已接入的工具全部打断
