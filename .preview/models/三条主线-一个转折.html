三条主线，一个转折

按时间看是一串发布，按机制看只有三条线在同时推进，外加 2025 年的一次转折。记住这四条，比记住模型名有用。

稠密 → MoE（2023 →）

总参数继续涨，但每个 token 只激活一部分专家。好处是同成本下容量更大； 代价是显存占用要按总参数算，路由和负载均衡也变复杂。

判断一个 MoE 模型值不值得试，看三件事：激活参数多少、专家粒度多细、有没有负载均衡损失。

预训练 → 后训练（2024 →）

预训练决定知识上限，SFT 与偏好优化决定「好不好用」。2025 年的增量更多来自 可验证奖励的强化学习，而不是更大的预训练语料——数学、代码这类有标准答案的任务先被吃透。

文本 → 原生多模态（2024 →）

从「拼一个视觉编码器」转向音频、图像、视频在同一套表示里训练。 语音端到端是分水岭：延迟和语气都变了，不再需要「ASR → LLM → TTS」三段拼接。

转折：推理即产品（2024-09 →）

o1 之后，推理不再是隐藏步骤，而是可以按 token 售卖的商品——思考链越长，账单越高。 GPT-5 又把这条路收回默认路由，说明「单独一个推理模型」只是过渡形态， 默认配置里带不带思考，才是长期形态。

怎么判断一条发布是不是真进展

看它是否改变了默认配置：默认上下文长度、默认是否思考、默认是否带工具。 只改排行榜分数的发布，多半是同一代能力的重新包装。
