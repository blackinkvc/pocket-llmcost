183 万张 B300 的口径边界：换算自洽 ≠ 口径成立，以及外部一手补充清单

⚠️ 本卡是口径与边界整理，不是超算评测。A036 给了满屏 TOP10 数值与一个极醒目的「183 万张 B300」，但数字分属三种完全不同的性质；先分层，再谈能拿来做什么。

作者自算等效值（第三类 · 可核验但未核验口径）：整列「≈B300（万张）」按图面底部「B300 单卡 FP64≈1.2 TFLOPS」换算，TOP500 官网没有这一列。换算完全自洽：2198.40 PFlop/s ÷ 1.2 TFLOPS = 183.20 万张，1809.00 → 150.75、1353.00 → 112.75、1012.00 → 84.33、1000.00 → 83.33、571.50 → 47.63、561.20 → 46.77、477.90 → 39.83、442.01 → 36.83、434.90 → 36.24，10 行逐项除得尽。⚠️ 与 A035「31.5 GB 既是候选又是可选」正好相反：那次是口径不自洽，这次是自洽。但自洽只说明算术对，不说明口径对 —— 单卡 FP64 取值、是否应把 HPL 双精度性能直接除以 GPU 峰值、是否忽略互连与内存瓶颈，作者都没论证；正文自己也写明「183万张只是理论性能的等效换算，不能代表实际需要多少显卡，更不能直接与 AI 训练算力画等号」。按「作者自定口径的等效值」留档，不写成英伟达 B300 规格、不写成实际卡数、不拿去补 AI 训练算力缺口。

一手已证实（外部，单列不并入正文）：TOP500 官网 11/2026 第 68 期（2026-11-16 SC26 芝加哥）+ 新华网 2026-11-23 —— 灵晟 / LineShine 第一、HPL 2.198 Exaflop/s、13,789,440 核、国家超级计算深圳中心（NSCS）/ 深圳云计算中心、LingKun 平台 + 304 核 LX2 + LingQi（灵启） 互连 + Kylin OS、HPCG 22.00 Petaflop/s 第一（新华网称领先第二名约 26%）；2026 年 6 月第 67 期 ISC2026 汉堡首次登顶、11 月卫冕、终结 El Capitan、2017 神威太湖之光以来首个登顶的中国系统；官网「TOP10 与 6 月版相比未变、仅 27 台新系统为史上最低」。⚠️ 官网搜索结果只给了第 1 名与 2025 年 11 月第 66 期的完整 TOP10（El Capitan 1.809 / Frontier 1.353 / Aurora 1.012 / JUPITER Booster 1.000 / Eagle / HPC6 / Fugaku / Alps / LUMI / Leonardo），没有给 11/2026 第 2–10 名的逐项数值 → 图面第 2–10 名仍按「图面口径 · 未逐项回一手核实」留档。

外部一手补充（公众号里没有，单列）：新华网 2026-11-23 另给 —— 国家超算深圳中心主任 / 总设计师卢宇彤；自研 LX2 CPU 首创在线加速的「全 CPU 超智融合」架构，HPC 与 AI 算力单芯片协同；搭载首颗国产 HBM，内存带宽较传统 CPU 提升 10 倍；自研「灵启」高速互联可支撑 200 万端口 / 10 万节点扩展；首创 100% 全液冷，能效比 52 GFlops/W；图灵奖得主、TOP500 联合创始人 Jack Dongarra 评价其「让世界看到了超算通向 AI for Science 的希望之光」。⚠️ 这些不写进公众号正文，也不拿去补 GH01 / GH03 的芯片与液冷工程细节缺口（那是另一层资料）。

措辞 / 单位差异并列不调和：① 正文「2.198 Exaflop/s」vs 图面「2,198.40 PFlop/s」—— 同一数值不同单位与精度，不是冲突；② 正文「超过 1300 万个计算核心」vs 官方「13,789,440 cores」—— 约数 vs 精确值，并列；③ 正文「自主设计的处理器和互连网络」vs 官方 LingKun / LX2 / LingQi / Kylin OS vs 新华网 LX2 CPU / 国产 HBM / 灵启 / 全液冷 —— 三层颗粒度不同，并列；④ 正文「再次拿下」「中国超算重回世界第一」vs 官方「6 月首登顶 / 11 月卫冕 / since Sunway TaihuLight in 2017」—— 「重回」可对应 2017 之后的空档，「再次 / 卫冕」一致，但不替作者统一措辞；⑤ og:description「最新一期」vs content_noencode「新一期」—— 一字之差并列。

层序与计数（不是统计）：4 个话题标签、10 行榜单、第 68 期 / 第 67 期 / 第 66 期是期号、10 个国旗是归属标记、「超过 1300 万个核心」是约数、appmsg_type: 9 是页面字段。⚠️ 别把「183.20 万张」当成第 11 个统计值，它是换算产物。

与库内榜单类资料的对照（只增不减）：T043 记过「榜单生态：谁在收集 AI 数据、四种来源与跟」、A019 是 AA-Video-I2V v2.1 单期截图、GC05 / G16 挂了很久「榜单类资料缺一手页与多期快照」。A036 第一次给榜单类补上了可点的一手页（top500.org 11/2026 第 68 期 + 新华网 2026-11-23），但仍不是多期快照：本库只有 11/2026 这一期，没有 6/2026 第 67 期或更早同口径图。⚠️ 不回改 A019 / T043 / GC05 / G16，只在 T088 里作说明，并把「多期快照」继续留作缺口。

证据等级：「公共榜单图卡 · 第 1 名核心数字经 TOP500 官网与新华网核实一致 · 等效换算列为作者自定口径且算术自洽 · 第 2–10 名仅图面口径 · 无榜单原页链接（页面 source_url 为空）、无抓取时间、无制图方」。比 A034 / A035 硬在有一手页且核上了，软在换算口径与全表仍未核。

一句话：这条的价值是「一个把 HPL 双精度性能折算成 GPU 等效卡数的口径样本」+「本库第一次核实成功的公共榜单」；凡是想从它读出 B300 实际保有量、AI 训练算力等价、11/2026 完整 TOP10 官方数值或液冷工程规格的，都属于越界。
