图面逐页 · 8 张 1086×1448 长图（页码 01/08–08/08）：

  • P1「英伟达 AI 与数据中心核心芯片进化史 —— 从一颗GPU到一座AI工厂」：六阶段总览 ①图形处理→通用计算（1999—2016）②通用计算→AI专用计算（2017—2019）③深度学习→大模型计算（2020—2023）④单颗GPU→超级芯片（2023—2025）⑤多GPU服务器→机架级系统（2024—2026）⑥AI工厂与智能体时代（2026）；代表产品 GeForce 256（2001，首款GPU）/ Tesla / Pascal P100（2016）/ Volta V100（2017，首款Tensor Core）/ Tensor Core / Turing T4（2019）/ A100（2020）/ H100（2022）/ H200（2023）/ HBM / Grace CPU / GH200 / GB200 / GB300 / NVLink / NVSwitch / ConnectX / BlueField / GB200 NVL72 / Rubin GPU / Vera CPU / Vera Rubin NVL72；底部「核心主线：算力提升 → AI专用化 → 显存升级 → 高速互联 → AI工厂」
  • P2「02 | GPU从图形处理到通用计算」：时间线 1999 GeForce 256（首款 GPU）/ 2006 CUDA / 2006—2010 Tesla·Fermi / 2012 AlexNet / 2016 Pascal P100（HBM2 + NVLink）；CPU vs GPU 对照；「这一阶段的关键技术」CUDA / Tesla / Fermi / Pascal / HBM2 / NVLink；本页结论「GPU 先凭并行计算能力脱颖而出，再通过 CUDA 进入通用计算，最终为 AI 训练奠定基础」
  • P3「03 | AI专用计算芯片诞生」：2017 Volta V100 首次引入 Tensor Core、2017–2019 Tensor Core 矩阵计算专用加速单元、2019 Turing T4 强化推理与低精度计算；CUDA Core vs Tensor Core；训练 vs 推理（V100 更偏训练，T4 更偏推理）；四个关键变化（AI专用化 / 矩阵计算提速 / 低精度计算开始重要 FP16·INT8 / 训练与推理开始分化）
  • P4「04 | 大模型时代的GPU升级」：三大瓶颈（算力不够 / 显存不够 / 通信不够）；A100（Ampere、TF32/BF16、MIG、HBM2e）/ H100（Hopper、Transformer Engine、FP8、更强 NVLink）/ H200（Hopper 升级版、HBM3e）；技术同步升级 Tensor Core 迭代 → 计算精度（TF32/BF16/FP8）→ HBM 升级（HBM2e/HBM3/HBM3e）→ 多 GPU 通信增强；结论「GPU 竞争不再只是比算力，而是算力、显存、带宽和互联能力的综合竞争」
  • P5「05 | 从GPU到CPU+GPU超级芯片」：演进 2023 Grace CPU → 2024 上半年 GH200 → 2024 下半年 GB200 → 2025 GB300；NVLink-C2C；「容易混淆」三种形态（单颗 GPU / 超级芯片 GH200·GB200·GB300 / 机架级系统 NVL72）；结论「英伟达不再只做单颗 GPU，而是开始围绕 CPU+GPU 协同设计整套计算单元」
  • P6「06 | 显存与高速互联：AI芯片真正的隐形战场」：HBM2 → HBM2e → HBM3 → HBM3e → HBM4；PCIe → NVLink → NVSwitch → ConnectX → InfiniBand / Spectrum-X → BlueField DPU；结论「AI 芯片性能不仅取决于计算核心，也取决于显存带宽和芯片之间的数据传输效率」
  • P7「07 | 异构计算体系：GPU、CPU、DPU、LPU如何分工？」：GPU（A100 / H100 / B200 / Rubin GPU）/ CPU（Grace / Vera）/ DPU（BlueField）/ LPU（语言处理器，代表产品 Groq 3 LPX）；「一次AI任务是如何协同完成的」用户请求 → CPU调度 → GPU训练/推理 → DPU处理网络与数据流 → LPU负责低延迟推理场景 → 返回结果；结论「未来的数据中心不再只有 GPU，而是多种芯片协同工作的异构计算体系」
  • P8「08 | Vera Rubin：从芯片到AI工厂」：「Vera Rubin 不是单一芯片，而是一套面向 Agent 时代的 AI 基础设施平台」；六组件 Rubin GPU / Vera CPU / NVLink 6·NVLink Switch / ConnectX-9 SuperNIC / BlueField-4 DPU / Quantum-X800·Spectrum-X；平台形态「单机架 → NVL72 → 多机架POD → AI工厂」；四个核心问题（通信瓶颈 / 内存搬运 / 推理成本 / Token效率）；最终结论「英伟达的进化，本质上是从卖一颗GPU，升级为提供整套AI工厂基础设施」
