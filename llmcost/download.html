装进墨山中台（推荐）

中台里三条路，都不用开终端。装完顶栏多一颗「Token 价格追踪」，刷新页面就出现，不用重启中台。

  1. 拖进去 —— 把 llmcost.moshanplug 拖到中台窗口任意位置，松手就装。
  2. 选文件 / 选文件夹 —— 中台右下角「插件」→ 装插件 → 选文件；手上有源码目录就点「选文件夹」，认得出 plugin.json 就行。
  3. 让它自己下 —— 同一处粘上网址点「去下载」：
    https://blackinkvc.github.io/pocket-llmcost/llmcost.moshanplug

装到 _插件/llmcost/，登记在 _工作台/plugins.json；数据仍然在你自己的 13-算价 目录里，升级不会动它。

以后出新版，中台右下角的「插件」会变成「N 项更新」，点开一按就换； 中台本体的新版也在同一个地方提示、跳去更新页。

三个可执行包都是单文件，解开双击就跑，不写注册表、不装服务；源码包要 Python 3.9+。 想当中台插件用、或者要改代码，下源码包。

装完打不开

macOS 会提示「无法验证开发者」。两条路：

右键点图标 → 打开 → 再点「打开」

或者命令行摘掉隔离标记：

xattr -dr com.apple.quarantine /Applications/llmcost.app

Windows 会弹 SmartScreen：「更多信息」→「仍要运行」。

这是因为没买签名证书，不是包有问题。校验和见下。

跑起来是什么样

双击后浏览器自动打开 http://127.0.0.1:8776/，就是这五页的完整版。 关掉浏览器窗口，后台进程会自己退（租约机制），不用管它。

数据存在本机 ~/Documents/AI项目/13-算价，代码和数据分家， 升级时直接换包就行，不会覆盖你填的价格。

首次运行会把内置的公开价目快照补进数据目录，只补缺、不覆盖。

命令行也能用

./llmcost --serve            # 起服务，默认 8776
./llmcost --serve --port 9000
./llmcost --snapshot         # 落一份看板和报告到 out/
./llmcost --json | head      # 打包好的数据打到 stdout

源码包的用法见仓库 README，./install.sh 一键装进中台。
