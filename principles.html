原理 · 历史

HOW IT WORKS · 1943 → 2025

不追求教科书式完整，只回答监控时最常遇到的那几个「为什么」： 为什么长上下文贵、为什么量化能提速、为什么 MoE 显存按总参数算、 为什么扩散模型加 ControlNet 就能锁姿势。

机制解释了「为什么这样算」，历史解释了「为什么现在是这样」。 两部分都拆成了独立报告，下面的机制索引可以直接点进去。

结论 / VERDICT

  1. 长上下文贵在两处，都不在参数。自注意力的计算量随序列长度平方增长，KV Cache 的显存随长度线性增长。参数规模决定「装不装得下」，序列长度决定「一次能塞多少并发」。
  2. decode 的瓶颈是带宽，不是算力。每生成一个 token 都要把全部权重从显存读一遍，所以理论速度 ≈ 带宽 ÷ 权重大小。量化加速的主要就是这一步：读的字节变少了。
  3. MoE 让显存先于算力成为门槛。总参数决定显存占用，激活参数决定单 token 计算量。看到「1T 参数」不等于需要 1T 稠密模型的算力，但确实需要 1T 的显存。

01

两段式推理 Prefill / Decode

2023-01

生成 · 工程口径，无单篇论文

输入并行算、输出逐字算；容量规划按这两段分开算，混在一起会算出错的并发数。

02

KV Cache

2020-06

生成 · vLLM 等推理框架

缓存已算过的键值，避免每生成一个字重算前文；长上下文吃显存的主因。

03

自注意力

2017-06

结构 · Transformer

每个 token 与前文所有 token 算相关性，计算量随序列长度平方增长。

04

多头与 GQA / MQA

2023-07

结构 · LLaMA 2 起成为默认

多个 Query 共享少量 KV 头，直接压缩 KV Cache，代价是表达能力略降。

05

FlashAttention

2022-06

结构 · Dao 等

不改变数学结果，只减少显存读写；它省的是 IO，不是 FLOPs。

06

稀疏注意力

2025-09

结构 · DeepSeek-V3.2-Exp

只算部分位置，用近似换长度；长上下文降价的直接来源。

07

MoE 混合专家

2021-01

结构 · Switch Transformer

显存按总参数、算力按激活参数；看到 1T 参数不等于要 1T 稠密的算力。

08

预训练

2020-05

训练 · GPT-3 / Scaling Laws

万亿级 token 上做下一词预测，决定能力上限，成本也最高。

09

监督微调 SFT

2022-01

训练 · InstructGPT

用高质量对话把「补全器」变成「助手」，不增加知识。

10

偏好优化 RLHF / DPO

2022-03

训练 · InstructGPT / DPO

用人类偏好排序调输出风格：更有用、更少有害、更愿意承认不知道。

11

可验证强化学习 RLVR

2025-01

训练 · DeepSeek-R1

只在能自动判对错的领域给奖励，数学与代码先被吃透。

12

test-time compute

2024-09

推理 · o1

用更多思考 token 换正确率，边际收益递减；简单任务上只是更贵更慢。

13

权重量化

2022-08

压缩 · GPTQ / LLM.int8

压到 8/4 bit，省显存与带宽；4 位在数学与长链推理上更容易掉点。

14

蒸馏

2015-03

压缩 · Hinton / 扩散步数蒸馏

大模型教小模型，或多步教少步；上限受教师与数据限制。

15

潜空间扩散

2021-12

图像 · Latent Diffusion / Stable Diffusion

先压到 VAE 潜空间再去噪，比像素空间省一个数量级算力。

16

条件注入 ControlNet / IPAdapter

图像 · ControlNet

不改变扩散本身，只把结构、风格或身份条件注入去噪过程。

一次生成到底在算什么

自回归生成分 prefill 和 decode 两段，前者吃算力，后者吃带宽。这一条区分能解释长上下文为什么贵、量化为什么提速、统一内存机器为什么慢。

推理成本显存 2025-11-24→

注意力与长上下文

每个 token 与前文所有 token 算相关性，计算量随长度平方增长。三种主流优化分别治不同病：FlashAttention 治 IO，GQA 治缓存，稀疏注意力治长度。

结构注意力长上下文 2025-11-24→

训练分三段

预训练定上限，SFT 把补全器变成助手，偏好优化调风格。2025 年多出来的第四段是可验证强化学习——只在能自动判对错的领域有效。

训练对齐 2025-11-24→

推理模型与思考预算

推理模型把「想」变成显式的 token：先写中间步骤再给答案。它更强是有条件的——题目越难越可验证，收益越大；简单任务上只是更贵更慢。

推理训练成本 2025-11-24→

MoE：总参数与激活参数

混合专家把 FFN 拆成多组，每个 token 只选 top-k 组计算。于是总参数决定显存，激活参数决定单 token 算力。这是理解开源模型规格表的第一道门槛。

结构显存MoE 2025-11-24→

扩散模型：图像是怎么出来的

训练时给图片逐步加噪，让网络学会预测噪声；生成时从纯噪声出发反复去噪。真正决定出图效果的是四个旋钮：步数、CFG、denoise、潜空间通道数。

图像扩散 2025-11-24→

量化与蒸馏

量化省显存与带宽，蒸馏省参数与步数，两者常被混为一谈。经验上 8 位几乎无损，4 位在数学、代码和长链推理上更容易掉点，能不能接受要用自己的任务测。

压缩显存部署 2025-11-24→

评估与幻觉

幻觉不是「模型撒谎」，而是下一词预测在缺乏依据时仍会生成流畅文本。分数不可比的原因有六个，其中基准污染和脚手架混淆最容易被忽略。

速查历史 2025-11-24→

时间线 ①：符号主义与连接主义（1943–1997）

AI 的头五十年换了三次主导路线：符号主义靠规则，连接主义靠可训练网络，中间夹着两次低潮。这一段的价值是看清「路线之争」从来不是纯技术问题。

历史时间线 2025-11-24→

时间线 ②：深度学习复兴（2006–2016）

十年里发生了三件关键的事：逐层预训练证明深层网络可训，ImageNet 提供了统一尺子，GPU 让训练变得可行。缺任何一件，深度学习都不会在 2012 年爆发。

历史时间线 2025-11-24→

时间线 ③：大模型奠基（2017–2022）

六年里定下了此后所有模型的基本形状：Transformer 做底座，预训练+微调做范式，缩放规律做决策依据，ChatGPT 把这一切做成了产品。

历史时间线 2025-11-24→

时间线 ④：多模态、推理与 Agent（2023–2025）

三年里三条线并行推进：多模态成为旗舰默认形态，推理从单独产品并回默认路由，Agent 从演示走进 IDE 和终端。2026 年这一段留空待补。
