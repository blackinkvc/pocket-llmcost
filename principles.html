01

一次生成到底在算什么

自回归生成分两段。Prefill 把整段输入一次性送进模型，所有 token 并行算， 吃的是算力；decode 每次只生成一个 token，却要把全部权重从显存读一遍，吃的是带宽。

INFERENCE数量级估算
prefill FLOPs ≈ 2 × N_params × N_tokens
decode 每 token 读权重 ≈ N_params × bytes_per_param
理论 tok/s ≈ 带宽 ÷ (N_params × bytes_per_param)

KV Cache ≈ 2 × layers × kv_heads × head_dim × seq × batch × bytes
  （2 = K 和 V；GQA 会让 kv_heads 远小于注意力头数）

这解释了三件事：第一，上下文越长，KV Cache 越占显存，能并发的请求越少； 第二，量化主要加速 decode，因为读的字节变少了； 第三，统一内存机器能装下大模型，但 decode 速度被带宽卡住。

02

Transformer 与注意力

每个 token 生成 Q、K、V 三个向量，用 Q 和所有历史 K 做点积得到权重，再对 V 加权求和。 causal mask 保证只能看前面，这就是「自回归」。

ATTENTION单头，省略 batch
Attention(Q, K, V) = softmax( Q·Kᵀ / √d_k ) · V

复杂度：O(n² · d)     n = 序列长度
长上下文成本主要来自这里，而不是参数规模

工程上有三种常见优化：FlashAttention 不改变数学结果，只减少显存读写； GQA / MQA 让多个 Query 共享少量 KV 头，直接压缩 KV Cache； 稀疏注意力只算部分位置，用近似换长度。三者可以叠加。

03

训练分三段

① 预训练 Pretrain

在万亿级 token 上做下一词预测，学到语言与世界知识。决定能力上限，成本最高。

② 监督微调 SFT

用人工或模型生成的高质量对话，把「补全器」变成「助手」。

③ 偏好优化 RLHF / DPO

用人类偏好排序调整输出风格：更有用、更少有害内容、更愿意承认不知道。

④ 可验证强化学习 RLVR

数学、代码这类能自动判对错的领域，直接用结果奖励训练推理链，是 2025 年的主要增量。

「后训练」这个词通常指 ②③④ 全部。它不增加知识，只改变模型使用知识的方式。

04

推理模型与 test-time compute

推理模型把「想」变成显式的 token：先写中间步骤，再给答案。训练时用 RL 奖励正确答案， 推理时用更多 token 换更高正确率。

TRADE-OFF直觉口径
总成本 ≈ 输入 token + 思考 token + 输出 token
正确率随思考长度上升，但边际收益递减
超过某个长度后，错误会开始自我强化

所以「推理模型更强」是有条件的：题目越难、越可验证，收益越大； 简单任务上，它只是更贵、更慢。GPT-5 把快慢思考做成自动路由，本质是在压这部分浪费。

05

MoE：总参数与激活参数

混合专家把 FFN 拆成很多组，每个 token 只选 top-k 组计算。 于是「总参数」决定显存占用，「激活参数」决定单 token 计算量。

MoE简化
显存 ≈ 总参数 × bytes_per_param
计算 ≈ 激活参数 × bytes_per_param（decode 读权重）
路由：每个 token 选 top-k 专家，需要负载均衡避免塌缩

这带来一个常见误判：看到「1T 参数」就以为需要 1T 稠密模型的算力。 实际计算按激活部分走，但显存仍要装下全部专家，所以 MoE 对显存更敏感、对算力更友好。

06

扩散模型：图像是怎么出来的

训练时给图片逐步加噪，让网络学会「预测这一步的噪声」；生成时从纯噪声出发， 反复去噪，最后得到图像。潜空间扩散（Latent Diffusion）先把图压到 VAE 潜空间， 再在潜空间里去噪，算力省一个数量级。

DIFFUSION关键旋钮
步数 steps     越多越细，但耗时线性上涨；蒸馏模型可压到 4–8 步
CFG            无分类器引导强度；越高越贴提示词，也越容易过饱和
denoise (i2i)  从参考图加噪到第 t 步再开始去噪；越低越像原图
latent 通道数  不同架构不通用，SDXL 4 通道 ≠ Z-Image 16 通道

图像侧的「Agent 化」体现在控制件：ControlNet 锁结构，IPAdapter 锁风格与身份， inpainting 锁局部。它们都不改变扩散本身，只是把条件注入去噪过程。 这就是为什么本地生图实例里，人物一律走 i2i 而不是纯 t2i。

07

量化与蒸馏

两者常被混为一谈，其实目标不同：量化省显存与带宽，蒸馏省参数与步数。

手段做什么主要收益主要代价
FP16 / BF16半精度权重通用基线显存占用最大
FP88 位浮点显存减半，精度损失小需要硬件与框架支持
INT8 / INT4整数量化 + 缩放显存显著下降，decode 提速低比特下细节与长链推理退化
GGUF面向 CPU / 混合推理的格式本地部署友好，可按层量化生态以 llama.cpp 为主
AWQ / GPTQ面向 GPU 的权重量化推理吞吐高需要校准数据
蒸馏大模型教小模型，或多步教少步小模型接近大模型，步数下降上限受教师与数据限制

经验上，8 位量化几乎无损；4 位在通用对话上可接受，但在数学、代码和长链推理上更容易掉点。是否可接受要用自己的任务测。

08

评估与幻觉

幻觉不是「模型撒谎」，而是下一词预测在缺乏依据时仍会生成流畅文本。 检索、引用、工具调用和「允许说不知道」都在缓解它，但都不能消除。

基准污染测试集进入训练语料，分数虚高。
单次采样只看一次结果，忽略方差。
脚手架混淆把工具与提示词的功劳算给模型。
人类偏好胜率不等于正确率，讨喜与准确是两回事。
分布外真实业务的长尾远多于基准。
成本维度不看 token 与延迟的评测没有工程意义。

本站在各板块页不收录具体分数，原因就在这里：没有统一脚手架、采样次数与成本的分数，放一起比较会误导。

09

符号主义与连接主义（1943–1997）

  • 1943

    McCulloch–Pitts 神经元模型

    用阈值逻辑描述神经元，第一次把「思考」写成可计算的网络。

  • 1950

    图灵测试

    图灵提出「机器能思考吗」的可操作判据：以对话 indistinguishable 为准。

  • 1956

    达特茅斯会议

    「人工智能」正式命名，符号主义成为此后三十年的主流路线。

  • 1958

    感知机

    Rosenblatt 提出可学习的线性分类器，连接主义第一次有可训练模型。

  • 1969

    《Perceptrons》

    指出单层感知机无法解决异或，神经网络研究进入第一次低潮。

  • 1986

    反向传播普及

    多层网络有了可行的训练方法，连接主义复兴。

  • 1989

    卷积网络识别手写数字

    LeCun 把卷积与反向传播结合，奠定视觉网络的基本结构。

  • 1997

    LSTM 与 Deep Blue

    序列建模有了长记忆结构；同年深蓝战胜国际象棋世界冠军。

10

深度学习复兴（2006–2016）

  • 2006

    深度信念网络

    逐层预训练让深层网络可训练，「深度学习」重新获得关注。

  • 2009

    ImageNet 发布

    大规模标注数据集，为之后的算力与模型竞赛提供同一把尺子。

  • 2012

    AlexNet

    GPU + 深层卷积在 ImageNet 上大幅领先，深度学习进入工业界。

  • 2014

    GAN

    生成对抗训练提出，图像生成有了新的范式。

  • 2015

    ResNet

    残差连接让上百层网络可训练，成为后续主干网络的标准件。

  • 2016

    AlphaGo

    深度网络 + 蒙特卡洛树搜索战胜李世石，强化学习进入公众视野。

11

大模型奠基（2017–2022）

  • 2017

    Transformer

    《Attention Is All You Need》去掉循环结构，成为之后所有大模型的底座。

  • 2018

    BERT 与 GPT-1

    预训练 + 微调分成两条路线：双向理解与自回归生成。

  • 2020

    GPT-3 / Scaling Laws / DDPM

    175B 参数展示上下文学习；缩放规律给出「堆规模」的经验曲线；扩散模型成为图像生成主线。

  • 2021

    CLIP / DALL·E / Codex / LoRA

    图文对齐、文本生成图像、代码生成与低秩微调先后出现。

  • 2022

    Chinchilla 与 Stable Diffusion

    「数据与参数同比例增长」修正了缩放策略；开放权重扩散模型催生本地生态。

  • 2022-11

    ChatGPT

    对话界面把大模型变成大众产品，RLHF 成为默认后训练手段。

12

多模态、推理与 Agent（2023–2025）

  • 2023-03

    GPT-4 发布

    多模态输入与更强的考试能力，闭源旗舰的门槛被抬高。

  • 2023

    LLaMA 与开源追赶

    开放权重模型让本地部署与二次训练成为可能。

  • 2024-02

    Sora 演示 / Gemini 1.5

    视频生成展示长时一致性；百万级上下文进入产品讨论。

  • 2024-05

    GPT-4o

    文本、视觉、语音端到端，延迟大幅下降。

  • 2024-07

    Llama 3.1 405B

    开放权重第一次接近闭源旗舰的量级。

  • 2024-09

    o1

    把推理链作为产品：用更多思考 token 换正确率，test-time compute 成为新维度。

  • 2024-11

    MCP 开源

    工具接入有了统一协议，Agent 生态开始标准化。

  • 2024-12

    DeepSeek-V3

    以较低训练成本达到接近头部的通用能力，MoE 路线受到关注。

  • 2025-01

    DeepSeek-R1

    开放权重的推理模型，蒸馏版带动一批小模型具备思维链。

  • 2025-02

    Claude Code / Claude 3.7

    编码 Agent 从补全走向「读写整个仓库并执行命令」。

  • 2025-03

    Gemini 2.5 Pro

    长上下文与推理结合，百万 token 成为旗舰标配讨论项。

  • 2025-04

    Llama 4 / Qwen3

    开放权重进入 MoE 与「思考模式可切换」阶段。

  • 2025-05

    Claude 4 / Veo 3

    编码 Agent 产品化；视频生成开始原生带音频。

  • 2025-07

    Kimi K2 / GLM-4.5 / ChatGPT Agent

    开放权重继续上探；通用 Agent 进入消费级产品。

  • 2025-08

    GPT-5

    快慢思考合并为自动路由，推理不再是单独售卖的产品线。

  • 2025-09

    DeepSeek-V3.2-Exp

    稀疏注意力把长上下文成本压下来，API 同步降价。

  • 2025-11

    Gemini 3 / Claude Opus 4.5 / K2 Thinking

    多模态、长任务与工具调用同时推进；开放权重继续逼近。这是本页知识基线的终点。
