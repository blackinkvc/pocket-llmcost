**8 个站逐条（图面逐字，按原样抄、不校正、不回官网核实）**：

- **01 React Bits｜创意动效，直接复制｜reactbits.dev**（WEB · REACT）：「170+ 个动态背景、文字、光标与 3D 组件，预览、代码和参数都放在一起」，「看到喜欢的效果就能直接带走」，适合 Hero 区与作品集页面。**怎么用**：先选最接近需求的组件，把链接和代码交给 AI，说明**保留运动机制，只替换配色、尺寸与文案**；一个页面先放 1 个主效果，确认不卡顿再增加细节。⚠️ 同图截图写「**165+ Free Creative Components**」，与正文 170+ 并列不调和
- **02 Aceturnity UI｜一秒做出高级感｜ui.aceturnity.com**（WEB · LANDING PAGE）：「聚光灯、3D 卡片、背景光束、滚动展示一应俱全」，不只有单个组件，还有能直接拼页面的完整区块，适合 AI 产品 / 作品集 / SaaS 官网。**怎么用**：找到相近 Demo 把链接发给 AI，说清**保留哪个动效、替换哪些视觉内容**；先复制一个区块跑通，再统一圆角、字体和颜色，避免页面像组件大杂烩
- **03 Magic UI｜克制但不无聊｜magicui.design**（WEB · PRODUCT UI）：「**150+** 个开源 React 动效，比炫技型网站更克制」，列表进入、数字增长、动态边框和状态反馈，适合后台 / 工具 / 产品页。**怎么用**：先让 AI 完成静态页面，再逐个加入动效；优先放在**首次进入、关键操作和状态变化**上，统一时长与缓动，只让重要信息动
- **04 Codrops｜高阶动效实验室｜tympanus.net/codrops**（WEB · CREATIVE CODE）：WebGL、GSAP、图片变形、滚动叙事和页面转场，「专门收录普通组件库里找不到的实验性效果」，每个案例常附思路与源码。**怎么用**：先完整看一遍 Demo，**只挑一个运动机制**让 AI 复现，并说明**不要照搬整套视觉**；上线前补上移动端降级、加载占位和 `reduced-motion`
- **05 LottieFiles｜手机端轻动效宝库｜lottiefiles.com**（WEB · iOS · ANDROID）：加载、成功、空状态、引导和品牌动画都能直接找到，可预览与调整颜色，支持 Web / iOS / Android，「体积小、接入快、跨端表现稳定」。**怎么用**：按产品语义搜 `success` / `loading` / `AI thinking`，下载 Lottie JSON 后交给 AI，补充**何时播放、是否循环、播放几次、结束后停在哪一帧**
- **06 Page Flows｜看真实操作和转场｜pageflows.com**（WEB · MOBILE FLOW）：展示真实产品的完整操作**录像**而非静态截图，按钮点击后如何响应、浮层从哪里进入、页面怎样衔接，Web 与手机流程都有。**怎么用**：搜 `onboarding` / 购买 / 订阅等流程，边看边记**触发—过渡—结果—大致时长**，把这四项连同截图交给 AI，实现后再对照录像逐帧调整节奏
- **07 Mobbin｜真实产品状态库｜mobbin.com**（WEB · iOS · ANDROID）：「**40 万+** 移动端与 Web 截图」，可连续查看一个真实流程的不同状态；虽不是纯动效库，却最适合确认**动效发生前后界面元素究竟改变了什么**。**怎么用**：选同一流程的状态 A 和 B，让 AI 准确还原布局，再描述**哪些元素移动、消失或被替换**，补出中间转场；节奏不确定时配合 Page Flows 录像验证
- **08 Recent.design｜追最新动效趋势｜recent.design**（WEB · MOTION · 3D）：「每天更新 Web、Interface、Motion 和 3D 案例」，作品新、风格跨度大，适合项目早期判断「现在流行什么」以及产品该走克制还是张扬。**怎么用**：不要只把截图丢给 AI，先拆成**触发方式、位移方向、透明度、缩放、时长和缓动**，再把参数写进提示词；每次只复现一个片段
