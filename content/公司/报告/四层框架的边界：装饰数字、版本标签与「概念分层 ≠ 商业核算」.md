**四类「看起来像数字、其实不是数据」的东西（按 [T038](../apps/数字的七类证据性质：演示%20·%20报价%20·%20示意%20·%20可核验计数%20·%20正文未载的图面结果.html) 第三类标示意 / 装饰）**：

- **00123**：Token 层仪表盘计数器里的插画装饰，**不是 Token 用量、不是计量示例、不是上限**；图面没有单位、刻度、口径
- **2026版**：只在标题里出现，页面正文与图面都没有版本依据、更新日期、修订说明，也没有 2025 版或往期图可对照 → 只是**标题版本标签**，不写成「第 N 版」或「年度更新」
- **①②③④**：四层的顺序编号，不是数量统计；「一张图」「五场景 / …」是文案与列举，省略号意味着场景未列全
- **18 个话题标签**：是分发用的标签，不是分类体系；#人工智能 还出现 2 次，不合并去重成 17 个，按原样全量记

**概念分层 ≠ 企业名单 ≠ 商业核算（本库 infra 线的三层，并列不合并）**：

- **[A031](https://mp.weixin.qq.com/s/xgudQE7ZRdteA0TmYpG4ig) / 本卡**：四层是**概念分层**——算力（燃料）→ 模型（智慧核心）→ Token（桥梁）→ Agent（执行者）→ 应用落地（场景）。回答「这些词是什么关系」，面向科普
- **[A013](https://mp.weixin.qq.com/s/vTN1C2sOudQJvDoXD970nA) → [T033](../companies/中国%2015%20家%20AI%20Infra%20企业：五大技术阵营、产品标签与五大商业方向.html)**：**企业名单**——15 家 AI Infra 企业、五大技术阵营、五大商业方向。回答「谁在做」，面向产业盘点
- **[A013](https://mp.weixin.qq.com/s/vTN1C2sOudQJvDoXD970nA) → [T034](../companies/页面附载的跨主题图组：Token%20工厂「五站销路%20·%20渠道矩阵%20·%20三本账」.html)**：**商业核算**——Token 工厂「五站销路 / 渠道矩阵 / 三本账」，把 Token 放到「实际 API 结算与划款」的出厂账里。回答「钱怎么走」，面向账本
- ⚠️ 同样一个 Token，[A031](https://mp.weixin.qq.com/s/xgudQE7ZRdteA0TmYpG4ig) 写的是「计量单位·消耗计费·上下文窗口 / 连接模型与价值的桥梁」，[T034](../companies/页面附载的跨主题图组：Token%20工厂「五站销路%20·%20渠道矩阵%20·%20三本账」.html) 写的是「出厂账里真金白银的现金流」。**两者互补但层次不同**，不能合并成一个框架，也不能拿 [T034](../companies/页面附载的跨主题图组：Token%20工厂「五站销路%20·%20渠道矩阵%20·%20三本账」.html) 的核算口径去「纠正」[A031](https://mp.weixin.qq.com/s/xgudQE7ZRdteA0TmYpG4ig) 的科普口径。图右中「谁更有兑现能力？」是**设问**，不是结论，别当成「哪一层的公司更赚钱」的判断

**证据等级**：写「**公众号原创概念图 · 一手页面与图面可查 · 无数据来源、无版本依据、无企业名单、无第三方核验**」。比 [A013](https://mp.weixin.qq.com/s/vTN1C2sOudQJvDoXD970nA)（同为图片型产业盘点，但给了 15 家具名企业与产品标签）更软：[A031](https://mp.weixin.qq.com/s/xgudQE7ZRdteA0TmYpG4ig) 连一个可核验的实体都没给。⚠️ 也别因为「没数据」就说它错——它是**面向非技术读者的速览框架**，本来就不承担数据职责；本库收的是框架本身，不是产业结论。

**与学习路线 / 硬件 / Agent 板块的挂接**：四层几乎一一对应库里既有板块（hardware 对应算力、model 对应模型、infra 对应 Token 的商业侧、agent 对应 Agent、case 对应应用落地），可作为 [T028](../principles/12%20步路线%20→%20本资料库栏目映射与当前缺口.html) 学习路线的**一张目录级速览图**；但它是**并列关系图**，不是学习顺序、不是依赖链、不是能力成熟度模型，不写进路线图当阶段。related 只做挂接，不改各板块结论。

**一句话**：这张图的价值是「把四个高频词摆到一条链上」，不是「给出 2026 年产业链的事实」；凡是想从它里面读出规模、份额、价格、排名或版本演进的，都属于越界。

> 整理说明：口径与边界整理卡，非原文观点；三层框架的划分、数值性质与证据等级为本库整理方法，不代表公众号或制图方立场。
