**四种框架并列（不合并、不互相纠正）**：

- **[A032](https://mp.weixin.qq.com/s/c5DlBqp_XiL_HQhjGTf95w) / [T074](../companies/Token%20经济全景：词元工厂为枢纽的四环节闭环（图面逐字）.html)｜地方产业生态闭环**：以「**词元工厂**」为枢纽，算电协同 → 模型供给 → 数据复用 → 产业应用，数据底座托底，反馈改善回环，价值放大；限定词「**地方** Token 产业生态」，落点「从模型服务走向**本地交付**与持续经营」。回答「一个地方怎么把 Token 服务做成可复用的生意」，面向**区域产业落地**
- **[A031](https://mp.weixin.qq.com/s/xgudQE7ZRdteA0TmYpG4ig) / [T071](../companies/一图看懂%20AI%20产业链（2026版）：四层冰山与五类落地场景.html)｜概念四层**：算力（燃料）→ 模型（智慧核心）→ Token（桥梁）→ Agent（执行者）→ 应用落地。回答「这些高频词是什么关系」，面向**科普速览**；Token 在这里是「计量单位·消耗计费·上下文窗口」
- **[A013](https://mp.weixin.qq.com/s/vTN1C2sOudQJvDoXD970nA) → [T033](../companies/中国%2015%20家%20AI%20Infra%20企业：五大技术阵营、产品标签与五大商业方向.html)｜企业名单**：15 家 AI Infra 企业、五大技术阵营、五大商业方向。回答「谁在做」，面向**产业盘点**
- **[A013](https://mp.weixin.qq.com/s/vTN1C2sOudQJvDoXD970nA) → [T034](../companies/页面附载的跨主题图组：Token%20工厂「五站销路%20·%20渠道矩阵%20·%20三本账」.html)｜商业核算**：Token 工厂「五站销路 / 渠道矩阵 / 三本账」，把 Token 放到「实际 API 结算与划款」的**出厂账**里；配车载语音四层穿透案例。回答「钱怎么走」，面向**供给侧账本**

**「词元工厂」与「Token 工厂」**：[A032](https://mp.weixin.qq.com/s/c5DlBqp_XiL_HQhjGTf95w) 图里写「词元工厂」，[A013](https://mp.weixin.qq.com/s/vTN1C2sOudQJvDoXD970nA) 写「Token 工厂」，**是同一概念的中文名与英文名**，但本库只在字面上并列，**不推断是同一发布方、同一系列或同一口径**（[A032](https://mp.weixin.qq.com/s/c5DlBqp_XiL_HQhjGTf95w) 未给制图方、[A013](https://mp.weixin.qq.com/s/vTN1C2sOudQJvDoXD970nA) 是「AI托肯说」）。⚠️ 更不能用 [T034](../companies/页面附载的跨主题图组：Token%20工厂「五站销路%20·%20渠道矩阵%20·%20三本账」.html) 的「出厂账 / 五站销路」去补 [A032](https://mp.weixin.qq.com/s/c5DlBqp_XiL_HQhjGTf95w) 的「地方产业生态」—— 一个算钱怎么结算，一个讲能力怎么组织成服务，层次不同。

**[A032](https://mp.weixin.qq.com/s/c5DlBqp_XiL_HQhjGTf95w) 里容易被误读的三处**：① 「**地方** Token 产业生态」是范围限定，正文没提，别把这张图当成全国产业链全景；② 「**数据底座**（授权治理·计量追溯·质量验证）」是**支撑层**，不是第五个环节，正文写的「底层通过……提供支撑」也是这个意思，但词不同；③ 「**价值放大 / 供给复用·场景复制·服务延伸·反馈改善**」是图底的价值表述，**不是指标、不是承诺、不是测算结果**，别读成「效率提升 N 倍」。

**证据等级**：写「**公众号原创概念图 · 一手页面与图面可查 · 正文为图面改写 · 无数据来源、无制图方、无企业名、无任何可核验数值、无第三方核验**」。比 [A031](https://mp.weixin.qq.com/s/xgudQE7ZRdteA0TmYpG4ig) 略复杂（多一层「改写式正文」与图面独有信息），但强度同档：连一个待核验计数都没有，全按 [T038](../apps/数字的七类证据性质：演示%20·%20报价%20·%20示意%20·%20可核验计数%20·%20正文未载的图面结果.html) 第三类「示意 / 装饰」留档 —— 01–04 是层序、「4 个关键环节」是标题计数、6 个话题标签是分发用、园区插画与风机光伏是装饰。

**与库内板块的挂接**：算电协同 → hardware（但 G04 芯片层仍空，别拿这一格当补充）；模型供给 → model；数据复用 / 授权治理 → kb / case；产业应用 → case；「本地交付 / 持续经营」与 [T034](../companies/页面附载的跨主题图组：Token%20工厂「五站销路%20·%20渠道矩阵%20·%20三本账」.html) 的出厂结算可做**对照**而非合并。related 只挂接，不改各板块结论；这张图是**闭环关系图**，不是学习顺序、不是成熟度模型，不写进 [T028](../principles/12%20步路线%20→%20本资料库栏目映射与当前缺口.html) 路线图当阶段。

**一句话**：四张图里 [A032](https://mp.weixin.qq.com/s/c5DlBqp_XiL_HQhjGTf95w) 最像「落地方案」，但它给的是**环节与闭环的名字**，不是某地真的跑通了的项目；凡是想从它读出地区、规模、订单量、单价或验收结果的，都属于越界。
