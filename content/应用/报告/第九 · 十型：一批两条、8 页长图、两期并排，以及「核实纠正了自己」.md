**③ 「首字被截一字」第三次，且同批两条**：[A036](https://mp.weixin.qq.com/s/o_C93hkiSzFeap_0YyfXKg)「最新一期 / 新一期」、[A037](https://mp.weixin.qq.com/s/QQbMio_My7u1i_ladamVkw)「这 / 缺这」都是虚词；[A038](https://mp.weixin.qq.com/s/Zj_XNUG315-AJ7fQY-Qshg)「**英**伟达 → 缺英」、[A039](https://mp.weixin.qq.com/s/tESp7Od1YgtSHT9tEPLK2w)「**11**月 → 1月」是**专名首字与数字首字符**，且两条同批 → 更像 `content_noencode` 字段切片特征而非偶然。规矩不变：**两处按原样并列、不补字、不调和**；og:description 与 content_noencode 都要读，别只读一个。

**④ 验零噪音凑齐三类，硬规矩共三条**：[A036](https://mp.weixin.qq.com/s/o_C93hkiSzFeap_0YyfXKg)「83.33」= **SVG path 圆弧坐标**；[A037](https://mp.weixin.qq.com/s/QQbMio_My7u1i_ladamVkw) `Dark`/`Live`/`Export`/`API` = **JS 框架变量名 / 函数名**；[A038](https://mp.weixin.qq.com/s/Zj_XNUG315-AJ7fQY-Qshg)「1999」= **XML 命名空间 URI** `http://www.w3.org/1999/xlink`、[A039](https://mp.weixin.qq.com/s/tESp7Od1YgtSHT9tEPLK2w)「18%/28%」= URL 编码 SVG path 坐标、「Google」= `isGooglePlay`。加上 [A035](https://mp.weixin.qq.com/s/yjAqx2IHAhFewtkBdpI8zw)「反向词别误列」，三条硬规矩是：**数字/英文命中先看上下文、反向词别误列、样式坐标 / 框架变量 / 命名空间都不算正文**。⚠️ [A038](https://mp.weixin.qq.com/s/Zj_XNUG315-AJ7fQY-Qshg) 正文里就有 Volta V100 / A100 / NVLink / Vera Rubin 等 19 个产品词，[A039](https://mp.weixin.qq.com/s/tESp7Od1YgtSHT9tEPLK2w) 正文里就有 6 个模型名与 Artificial Analysis，全都**不是图面独有**。

**⑤ 首次「回一手核实纠正了自己的预判」**：[A038](https://mp.weixin.qq.com/s/Zj_XNUG315-AJ7fQY-Qshg) 图面 P7 把「LPU / Groq 3 LPX」列进英伟达异构体系，本库初判「跨厂商混入」，回一手后 NVIDIA 官网确有 **NVIDIA Groq 3 LPX** 产品页 → **按官网记为英伟达产品线，不判错、不删**。⚠️ 这条比 [A036](https://mp.weixin.qq.com/s/o_C93hkiSzFeap_0YyfXKg)「核实成功也不全表升格」、[A037](https://mp.weixin.qq.com/s/QQbMio_My7u1i_ladamVkw)「仓库存在 ≠ 快照已核」又多一层：**核实不仅可能「没核上」，还可能「推翻整理者自己的先验」**。以后遇到「看着像错」的图面内容，先回一手再定性，别凭旧知识判混入 / 判错。

**⑥ 两期并排 ≠ 多期同口径快照**：GC05 / G16 / GS04 挂了很久的「榜单类缺一手页与多期快照」，[A039](https://mp.weixin.qq.com/s/tESp7Od1YgtSHT9tEPLK2w) **第一次在同一篇里给到 10 月 + 11 月两期**；但两期**版本（v5.0.1 vs 10-09+LMarena）、数值含义（分数区间 vs 百分比）、档位集合（F vs Google）、分档声明全不同** → 正文「SSS 从 2 个到 4 个」是**跨口径对比**，不能写成趋势，也不能当「多期同口径快照」把旧缺口勾掉。⚠️ **[A019](https://artificialanalysis.ai/video/leaderboard/image-to-video) / [T043](../apps/榜单生态：谁在收集%20AI%20数据、四种来源与跟进的代价.html) / GC05 / G16 / GS04 / GSK06 / [T061](../agents/GitHub%20Skills%20本周飙升榜%20TOP%2010：热度是入口，价值要放回具体任务.html) / [A025](https://mp.weixin.qq.com/s/6SkEqqZzXKECkn1gHRnnfQ) / GM05 一条都不回改**，只在 G44 记进展。这是「有了新样本」与「缺口被补上」的又一次分开。

**⑦ 核实范围继续分层，别顺手升格**：[A038](https://mp.weixin.qq.com/s/Zj_XNUG315-AJ7fQY-Qshg) 三层 = 官网证实的产品名 / 平台形态（含 LPU 归属纠正）｜图面年份表与结论句未核｜正文大纲；[A039](https://mp.weixin.qq.com/s/tESp7Od1YgtSHT9tEPLK2w) 三层 = 官方 v5 与部分模型名｜图面 v5.0.1、9 个分数区间、两张全表、约 60 个模型名未核｜作者自述「非官方评级」。⚠️ **产品名被证实 ≠ 年份表被证实；v5 存在 ≠ v5.0.1 全表已核**。[A038](https://mp.weixin.qq.com/s/Zj_XNUG315-AJ7fQY-Qshg) 还留了一处**图内硬矛盾**（GeForce 256 P1「2001」vs P2「1999」，官方是 1999）与一处**层级混淆风险**（[A036](https://mp.weixin.qq.com/s/o_C93hkiSzFeap_0YyfXKg) 的 B300 显卡 ≠ [A038](https://mp.weixin.qq.com/s/Zj_XNUG315-AJ7fQY-Qshg) 的 GB300 超级芯片），都并列不调和。

**⑧ 缺口回写**：[T023](../apps/取证记录：二十三批资料的可见边界与补全来源.html) 扩到二十二批共 33 条取证；[T038](../apps/数字的七类证据性质：演示%20·%20报价%20·%20示意%20·%20可核验计数%20·%20正文未载的图面结果.html) 结果段补「一批两条 / 8 页长图 / 两期并排 / 首字截字 / XML 命名空间验零 / 预判被纠正 / 跨口径对比」；新增 **G43**（英伟达各代产品官方发布年表与规格、图面年份冲突回一手、LPU 与 Vera Rubin 组件一手页）、**G44**（Artificial Analysis v5.0.1 一手页、两期同口径快照、10 月 ※ 图例与百分比含义、约 60 个模型名逐项核实）；hardware 补 **GH06 / GH07**、model 补 **GM06 / GM07**、case 补 **GC12**；G10 / G11 同步；维护约定第 42 条固化。⚠️ 两篇页面与 21+9 张图都完整，**不进 G07 内容待补、不进 G08 视频样本**。

一句话结论：这一批把库往前推了三格 —— **从「一批一条」到「一批两条按主用途分栏」**、**从「单期榜单」到「两期并排但先核口径」**、**从「核实可能没核上」到「核实可能推翻自己的预判」**。最容易被漏的不是摘要太短，而是**两期图摆在一起就默认它们能比**、以及**看着像错就先判成错**。
