以下为基于 [A014](https://mp.weixin.qq.com/s/930qfWClyp1PJSKNSe9B5w)–[A017](https://mp.weixin.qq.com/s/CJoJ6Ch2nOAZqX5EKb2shA) 四条图片型资料，由 [A018](http://yb.woa.com/62oPBlyl0U0) 视频型资料补入第六类、[A019](https://artificialanalysis.ai/video/leaderboard/image-to-video) 榜单截图补入快照写法、[A020](http://yb.woa.com/DjfzMFlnxuO) 自动解析稿补入第七类的归纳延伸：这些原文都没有讨论「数字该怎么标注」。因与 [T032](../apps/观点型资料的证据等级：个人实测怎么收进库才不会被当成事实.html)（观点型资料的证据等级）性质不同——那张管**整篇**是什么性质，本卡主要管**某一个具体数字**是什么性质（第七类扩到整层转述）——按同板块不同主题并列成卡。

② **作者报价 / 成本估算**：[A015](https://mp.weixin.qq.com/s/_DI8rxczyjpas4362-Ub9Q) scroll-world 的 $2.99（8 秒俯冲 1080p · Seedance 2.0）、$1.87（5 秒过渡）、≈$27（6 场景全链）、≈$11（720p）、3 美元 480p 预览、「六位数报价」对比，都是文章给的估算与图面报价，没有账单、厂商定价页或复核口径；同一成本在图面 ≈$27、05/05「30 美元上下」、文字版「27-30 美元」三种约数并列不调和。

③ **示意数值**：[A016](https://mp.weixin.qq.com/s/yd-qvdazH_TJBgWYm_nNUw) 降维全篇的 768D → 2D、256 / 768 / 1536 / 4096 维、示例向量 0.12 / -1.03 / 0.89、Var(Xw) 公式、各张散点图，图面多处标「示意 / 示例」，是教学用构造值，不能当某模型规格或实测结果。

④ **可核验但未核验的计数**：[A014](https://mp.weixin.qq.com/s/930qfWClyp1PJSKNSe9B5w)「开源 10 天近 2000 星」、[A015](https://mp.weixin.qq.com/s/_DI8rxczyjpas4362-Ub9Q)「开源三个月 11.1k Star」「MIT」「11 月 14 号」这类数字与声明，理论上能去仓库核对，但本库按图面原样记录并统一标「未去外部核实」，不替作者验证、也不凭印象改写。

⑤ **正文完全没写、只在图里的结果数值**（[A017](https://mp.weixin.qq.com/s/CJoJ6Ch2nOAZqX5EKb2shA) 新增，也是最容易被漏掉的一类）：MatMaster 那篇正文只给了「十组参数 / 400 次模拟 / 46.6 分钟」等汇总数字，但八种 FCC 金属位错宽度的具体 Å 值、四组配方比例、双芯光纤的几何与折射率参数、三个模式的折射率增量**全部只存在于配图中**，图注也只解释口径不给数值。这类数值既不是演示也不是示意，是文章声称的计算结果，但**正文本身没复述**——所以逐张读图不是可选项，漏了就等于漏掉一半结论。标注方式：写清「来源＝图面 / 正文未载 / 未外部复核」，与①②类一样不能当已验证的性能指标。

⑥ **转述中被改变了语义的数值**（[A018](http://yb.woa.com/62oPBlyl0U0) 新增，最该警惕的一类）：视频描述把「LOCKER 求解矩阵的**所需内存**从 42PB 降到 58MB」写成了「把 42PB 的**天文级数据压缩**到 58MB」——数字分毫不差，性质完全变了：前者是代数结构优化（转置系数矩阵、解锁偏 Frobenius 映射）让一个原本建不出来的矩阵变得可建，后者听起来像违反信息论下限的通用压缩术。同一视频还把「TII McEliece 挑战 94 个实例里 55 个首次有解」揉进「攻破 NIST 后量子候选、55 道人类从未解开的难题」，把两类不同目标混成一句。处理方式：**不靠数量级直觉判定真假，也不照抄转述**，而去找一手来源把口径校正回来，并把「转述写法 / 一手口径 / 差在哪」三者并列留档。见 [T041](../apps/MiniMax%20内部模型%20MIM%20密码分析战绩：视频描述%204%20项声称%20×%20一手口径交叉校验.html) / [T042](../apps/战绩展示类视频：公开%20PoC、二值判定与「转述的转述」怎么标证据等级.html)。

⑦ **自动解析稿里的专名 / 数字 / 语义三类错乱**（[A020](http://yb.woa.com/DjfzMFlnxuO) 新增，是一整层转述而非某一个数字）：带时间轴的「视频解析内容」已经是机器转述，这次一篇里三类齐发 —— 专名（MemmTensor→MemTensor、MemmT-AgentBench→MemoryAgentBench）、字符数字（23.67→23.87、S5.08→53.08）、语义（「经验写入提供持续微调」实为冻结主干只更新运行时状态；「13M 内部记忆」实为动态记忆状态大小）。与前六类的区别：⑥ 是**某一个数字**被改了语义，⑦ 是**整层转述**把专名、数字、语义一起漂了，且常常「页面可见标题反而比解析稿更严谨」。处理方式：解析稿按原样全量记录并标「非逐帧取证」，再**三类都回一手核对**，把「转述写法 / 一手口径 / 差在哪」三者并列留档；查不到的标「来源不明 / 疑似 OCR」，不删也不补。见 [T044](../agents/MemT-1.0-Pro%20记忆原生模型：视频解析稿%204%20段时间轴%20×%20一手口径逐条校正.html) / [T046](../apps/带时间轴的视频自动解析稿：四类错乱与怎么标证据等级.html)。
