**一手来源交叉校验**（这是本卡最关键的一层）：本轮检索到了 **MiniMax 官方技术博客**《Practical cryptanalysis with MiniMax's latest Internal Model》（minimax.io/blog/practical-cryptanalysis-with-minimaxs-latest-internal-model，2026-11-20 发布 / 11-22 对外公布），以及央广网、上海证券报、北京日报等多家报道与 GitHub 仓库 MiniMax-AI/Research 的转述。⚠️ 以下**只用于校正视频描述的口径，不冒充视频画面内容**；这些外部来源尚未单独建台账，链接留作线索：

- **模型名对得上**：MIM = MiniMax's Internal Model，是未公开发布的内部研究模型；官方称已开放合格研究者申请测试。视频写「最新内部模型 MIM」无误
- **③ 是语义错置，不是数据压缩**：官方口径是 —— 后量子候选 **LOCKER** 的秩度量译码问题原本需要构建 5.72×10⁸ 列、约 **42PB 内存**的求解矩阵，MIM 通过**转置系数矩阵、解锁偏 Frobenius 映射、锁定未知空间**，把所需内存降到 **58MB**，2 秒内恢复全部参数集共享密钥。数字 42PB / 58MB 完全一致，但被降的是**求解矩阵的规模**，不是「42PB 天文数据被压成 58MB」。这是一次代数结构优化，不是通用无损压缩，二者性质完全不同（详见 [T038](../apps/数字的七类证据性质：演示%20·%20报价%20·%20示意%20·%20可核验计数%20·%20正文未载的图面结果.html) 第六类）
- **② 的倍数有特定对象与区间**：官方与报道口径是 **TII McEliece 国际密钥恢复挑战**——共恢复 **94 个实例**私钥（其中 **55 个为首次**），单台 64 核服务器耗时 **1.80–5.36 秒**，对比此前 CRYPTO 2026 论文纪录 **9.20 小时**及 Anthropic 方案，实测加速 **6,180–43,400 倍**。所以「43400 倍」是区间上限、特定挑战、特定对照基线，不是笼统的「比 Anthropic 多 GPU 集群快 43400 倍」。另在 HAWK-256 上单核约 30 分钟 vs Anthropic 96 核 3 小时 42 分，按 CPU 核时折算约 **690 倍**——两个倍数别混
- **① 把两类目标揉成了一句**：官方把成果分三类 —— (a) 历届 NIST 标准化竞赛**历史落选候选**（Tier 2，含 SHA-3 候选 Waterfall-256 / Blender-256、后量子候选 LOCKER / ROLLO-I-128 / DRS / RQC-128 / LAC-128）；(b) 顶会顶刊与竞赛优胜方案（COLM、SBC-VOLE、ARADI 等）；(c) 公开数学挑战实例（TII McEliece、HAWK）。**55 道首次解出的是 (c) 里的挑战实例，不是 NIST 候选**；且 Waterfall-256 / Blender-256 是哈希竞赛候选、并非后量子算法，传播中常被混为一谈
- **⚠️ 必须一并收的边界**：官方明确写「研究聚焦学术设计、历史竞赛候选与公开挑战参数，**不影响现行主流密码标准**」（AES / RSA / SHA-256 未涉及）；部分「攻破」是把 NIST IR 8309（2020）已发表的人类代数攻击转成单核秒级可运行求解器；发现已提前同步受影响方案作者；推理轨迹以技术报告与 PoC 代码形式公开在 MiniMax-AI/Research

**官方口径下的代表性结果**（供对照，全部标为发布方口径、未独立复现）：Waterfall-256 单核 0.045 秒首个实用碰撞；Blender-256 全轮碰撞 0.36–2.3 秒；LOCKER 42PB→58MB / 2 秒；ROLLO-I-128 单核约 6 秒由公钥恢复等价私钥；DRS 参考代码把 `&&` 误写成 `&`，0.1–0.8 秒零查询伪造签名；RQC-128 随机采样泄露 0.41 秒；LAC-128 解密失败分支哈希未初始化内存；COLM 2 次加密查询完成「差异消失」伪造；SBC-VOLE 凭 1 个已知签名 0.06 秒恢复完整私钥；ARADI 实用密钥恢复由 5 轮推进到 8 轮；TII McEliece 94 实例 / 55 首次 / 1.80–5.36 秒；HAWK 单核 30.9 分钟、安全估计再降 9.3–23.8 比特。评测基准 **CryptanalysisBench（NeurIPS 2026，ETH Zurich / Anthropic 等构建）Tier 2**：135 个经公开评审但此前无已知实用攻击的方案 + 7 个生产级挑战方案。
