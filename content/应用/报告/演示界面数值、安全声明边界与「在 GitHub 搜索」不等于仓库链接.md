**界面演示数值（第一类：演示截图快照 · 未回一手核实）**：「已测量候选文件 **31.5 GB**／已选择垃圾 **23.9 GB**，当前可选择 **31.5 GB**，其中 **3.4 GB** 需要你确认」——同一行里 **31.5 既是候选又是可选**、23.9 已选与 3.4 待确认并列，**口径不自洽，照抄不调和、不取平均、不替作者算总账**。三组「发现 x · 已选 y」：系统垃圾 **6.3 / 6.3**、应用缓存 **8.3 / 5.7**、浏览器缓存 **1.5 / 1.5**；逐项：用户日志 **1.3 GB**、临时文件 **860 MB**、系统服务缓存 **2.4 GB**、废纸篓 **1.8 GB**、飞书 **3.1 GB**、网易云音乐 **2.6 GB**、微信 **1.9 GB**、VS Code **740 MB**。⚠️ 全是 `/Users/demo/...` 路径下的界面快照，与 [A028](https://mp.weixin.qq.com/s/tEwu2LbeQiSij2Sz_CN8Tw) → [T064](../agents/麦田补充：仓库、协议、Star%20数与运行条件（补%20GA04，不回改%20A014）.html) 已标的「**演示数据**」同性质，**不写成磁盘实测、不写成清理效果、不累计成空间收益**。

**措辞口径并列（不调和）**：正文「安装包**才** 5 MB」（精确宣称）vs 图面「安装包**约** 5 MB」（约数）；正文「没有账号、没有遥测」vs 图面「**本地运行**」；正文「免费开源（**MIT**）」vs 图面「免费开源 · 本地运行」与落款「优质应用推荐 | 免费开源」。⚠️ 三组都是同一篇里两种说法，各自留档、不互相补全、不拿一个去证另一个。

**安全声明只在正文，图面没给验证**：「垃圾按系统、应用缓存、浏览器、开发工具分组列出，逐项勾选、**随时能停**」「你自己的文件**只移进废纸篓，删了还能拿回来**」「没有账号、没有遥测」「**免费开源（MIT），没有限免期限**」「Mac 版**已签名并通过公证**，Windows 安装包**未签名**，SmartScreen 拦截时点「**仍要运行**」」。图面里能互证的只有「逐项勾选」图标与「废纸篓」条目；⚠️ 但图面废纸篓那句「**只清扫描时已在废纸篓的内容，清空后不可恢复**」与正文「删了还能拿回来」**措辞方向不同**，按并列留档、不替作者调和、不推断哪句覆盖哪句。签名 / 公证 / 未签名 / SmartScreen 全无证书、哈希或下载页可核。

**版本号与计数**：「**Cleanzo v0.4.1**」只在界面左下角、回 HTML 验零 0 次 → 是**图面版本号**，不是发布公告，不推断发布时间、不推断是否最新版。5 个话题标签、三组「发现/已选」、侧栏 5 个分组都是**层序与界面计数**，不是统计。⚠️ [A028](https://mp.weixin.qq.com/s/tEwu2LbeQiSij2Sz_CN8Tw) 图面给过「MIT · Node.js · **1,481★**」，本条**没有 Star 数、没有运行条件、没有依赖版本** —— 同号不代表同信息量，不拿 [A028](https://mp.weixin.qq.com/s/tEwu2LbeQiSij2Sz_CN8Tw) 的字段来补 [A035](https://mp.weixin.qq.com/s/yjAqx2IHAhFewtkBdpI8zw)。

**「在 GitHub 搜索」≠ 仓库链接**：全文 `github.com` / `releases` / `git clone` / `echoVic/cleanzo` **0 次**，`source_url` 为空。[A028](https://mp.weixin.qq.com/s/tEwu2LbeQiSij2Sz_CN8Tw) 至少给了仓库名 mdldm-maitian + 作者 CzzzzzzJ + 图面 1,481★ + 运行条件；本条只有搜索词 `cleanzo` + GitHub 作者名 `echoVic`。⚠️ 按「**文字指引**」留档，**不拼 `github.com/echoVic/cleanzo`、不补 README / LICENSE / release、不回一手核实、不建独立项目台账**；也别把「免费开源（MIT）」当成已核验许可文件。

**同号同系列对照（并列不合并）**：[A028](https://mp.weixin.qq.com/s/tEwu2LbeQiSij2Sz_CN8Tw) 与 [A035](https://mp.weixin.qq.com/s/yjAqx2IHAhFewtkBdpI8zw) 同号「优质应用推荐」、同「｜免费开源」标题、同「在 GitHub 搜索 XXX，认准作者 YYY」句式、同「免费开源（MIT），没有限免期限」、同「免费下载」按钮 + 三图标 + 落款、同 6 组裁图规格；但 **[A028](https://mp.weixin.qq.com/s/tEwu2LbeQiSij2Sz_CN8Tw) 归 agent（多平台发布工作台）/ [A035](https://mp.weixin.qq.com/s/yjAqx2IHAhFewtkBdpI8zw) 归 case（本地清理器）**，一个补了 GA04 仓库与协议，一个连仓库全路径都没给。⚠️ 别因为同号就把两条写成同一项目的两期，也别把 [A028](https://mp.weixin.qq.com/s/tEwu2LbeQiSij2Sz_CN8Tw) 的「1,481★ / Node.js 22.5+」搬到 Cleanzo。

**证据等级**：写「**公众号开源工具推荐卡 · 一手页面与 8 张图面可查 · 正文短而完整但无仓库 / 证书 / LICENSE 链接 · 全部数值为界面演示快照、未回一手核实 · 无原创声明、无制图方、无数据来源**」。比 [A034](https://mp.weixin.qq.com/s/iMnx_LuS2x5Znk2MkhdjTg) 软在**连一个可点的一手链接都没有**，比 [A028](https://mp.weixin.qq.com/s/tEwu2LbeQiSij2Sz_CN8Tw) 软在**缺仓库名与 Star 快照**；硬在图面完整可读、水印版与头像都能补上号名证据。

**一句话**：这条的价值是「一个把 Claude Code / Codex / 本地模型缓存单独列出来的清理器」这个产品形态，以及同号开源推荐系列的第二次样本；凡是想从它读出真实清理量、安装包实测大小、MIT 许可文件、签名证书或仓库 Star 的，都属于越界。
