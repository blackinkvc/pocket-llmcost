以下为基于 [A036](https://mp.weixin.qq.com/s/o_C93hkiSzFeap_0YyfXKg) 的归纳延伸：原文没有讨论取证与归类方法。因与 [T086](../hardware/全球超算%20TOP10%20与「183%20万张%20B300」：正文全量、图面%2010%20行表与一手核实结果.html)（事实）、[T087](../hardware/183%20万张%20B300%20的口径边界：换算自洽%20≠%20口径成立，以及外部一手补充清单.html)（口径边界）性质不同 → 并列成卡，归 case（与 [T023](../apps/取证记录：二十三批资料的可见边界与补全来源.html) / [T038](../apps/数字的七类证据性质：演示%20·%20报价%20·%20示意%20·%20可核验计数%20·%20正文未载的图面结果.html) / [T085](../apps/同号同系列第二条怎么收：按主用途分栏、搜索词不算仓库、演示数值单列.html) 同栏目讲取证方法）。

**② 三层证据必须分开、互不补全**：**一手已证实**（官网 / 新华网：LineShine 第一、2.198 Exaflop/s、13,789,440 核、NSCS、LingKun / LX2 / LingQi / Kylin OS、HPCG 22.00 PFlop/s、6 月首登顶 11 月卫冕）；**作者自算等效值**（183.20 万张及整列 ≈B300，按单卡 FP64≈1.2 TFLOPS，官网无此列）；**图面独有**（TOP10 全表 / 国旗 / 副标题 / 底部注 / 水印，回 HTML 验零 0 次）。⚠️ **核实成功也不能顺手把全表升格**：第 1 名证实了，第 2–10 名仍只是图面口径；官网搜索结果没给 11/2026 第 2–10 名逐项数值。这是本批最该记住的一条。

**③ 算术自洽 ≠ 口径成立**：10 行 ≈B300 逐项除以 1.2 TFLOPS 都除得尽（与 [A035](https://mp.weixin.qq.com/s/yjAqx2IHAhFewtkBdpI8zw)「31.5 GB 既是候选又是可选」的不自洽形成对照），但自洽只说明除法没算错。**单卡 FP64 取值、HPL 双精度能否直接折算 GPU 峰值、互连与内存瓶颈是否可忽略**都没论证；正文自己还专门写了两行免责（「不能代表实际需要多少显卡，更不能直接与 AI 训练算力画等号」）。以后遇到「等效 X 万张卡 / 等效 Y 台机器」一律按**作者自定口径的等效值**收，不写成厂商规格。

**④ 验零遇到数字命中，先看上下文**：「83.33」在原始 HTML 里命中 10 次，全是内联 SVG path 的圆弧坐标 `83.333`，不是图面第 5 行。⚠️ 这是继 [A035](https://mp.weixin.qq.com/s/yjAqx2IHAhFewtkBdpI8zw)「别把正文词误列进验零清单」之后的**反向陷阱**：别把样式坐标当成「正文里也有」。同理，og:description「最新一期」与 content_noencode「新一期」一字之差、4 个标签这次是单层 `\x26lt;a ... \x26gt;` 转义（`topic-id` 原始 HTML 24 次可见，区别于 [A035](https://mp.weixin.qq.com/s/yjAqx2IHAhFewtkBdpI8zw) 双层 / 解码前 0 次）—— 都按原样并列，不替作者选一个。

**⑤ 完整竖版与裁剪版要分开摆**：8 张图去重 6 组，主图 3 份副本（含 1 份带「公众号 · 恭喜你有猫了」水印），另有 3 份**不同裁法**的裁剪版（1280×1706 截掉序号 / 国旗 / B300 列右半、1280×1280 截掉顶部大标题与第 10 行 / 数据来源注、1280×720 只剩第 02–07 行中段）。⚠️ **换算口径「单卡 FP64≈1.2 TFLOPS」和数据来源注只在完整竖版里能看到** —— 裁剪版会把这两句裁掉。以后遇到「榜单长图 + 多个裁剪副本」，**主证据只认完整版**，裁剪版只用来佐证号名水印与版式，不用来抄口径。

**⑥ 归类与旧卡边界**：归 **hardware** 主板块（算力底座），related 挂 infra / model / ai4s / case，**不新建栏目**（沿用 [A030](http://yb.woa.com/14N0XXeQcgj) 起的克制）；不因为「中国超算重回第一」归 infra 产业侧，也不因为新华网提 AI for Science 归 ai4s。⚠️ **GC05 / G16 / [A019](https://artificialanalysis.ai/video/leaderboard/image-to-video) / [T043](../apps/榜单生态：谁在收集%20AI%20数据、四种来源与跟进的代价.html) 一条都不回改**：[A036](https://mp.weixin.qq.com/s/o_C93hkiSzFeap_0YyfXKg) 是首次给榜单类补上可点一手页，但**仍不是多期快照**（本库只有 11/2026 一期，缺 6/2026 第 67 期同口径图），所以「多期快照」继续留缺口，只在本卡与 G40 里说明进展。

**⑦ 七型齐了**：[A031](https://mp.weixin.qq.com/s/xgudQE7ZRdteA0TmYpG4ig) 引子式 / [A032](https://mp.weixin.qq.com/s/c5DlBqp_XiL_HQhjGTf95w) 改写式 / [A033](https://mp.weixin.qq.com/s/ryLsLKE6YTtK7nMQLjdMqQ) 纯图清单 / [A034](https://mp.weixin.qq.com/s/iMnx_LuS2x5Znk2MkhdjTg) 摘要极简·正文藏在 JS 字段 / [A022](https://mp.weixin.qq.com/s/udXF9FEP6SCyeqIxo0YqWA) 同版式多页长图 / [A035](https://mp.weixin.qq.com/s/yjAqx2IHAhFewtkBdpI8zw) 短正文完整·演示截图承载数值 / **[A036](https://mp.weixin.qq.com/s/o_C93hkiSzFeap_0YyfXKg) 短正文完整·公共榜单·有一手页可核**。⚠️ 第六、七型都「正文短而完整」，区别只在**有没有权威一手页**；处理流程因此从「一律不核实」变成「先分三层再收」，但「不替作者校正、并列留档、只增不减」三条没变。

**⑧ 缺口回写**：[T023](../apps/取证记录：二十三批资料的可见边界与补全来源.html) 扩到二十批共 30 条取证；[T038](../apps/数字的七类证据性质：演示%20·%20报价%20·%20示意%20·%20可核验计数%20·%20正文未载的图面结果.html) 结果段补「公共榜单型 / 首次核实成功 / 换算自洽 / SVG 坐标验零陷阱」；新增 **G39**（11/2026 第 2–10 名逐项一手数值、榜单原页链接与抓取时间、多期快照）、**G40**（B300 单卡 FP64≈1.2 TFLOPS 的口径依据、HPL 折算 GPU 峰值的方法论证、新华网补充的工程细节回一手）；hardware 板块补 **GH04 / GH05**；G10 / G11 同步（Exaflop vs PFlop、1300万 vs 13,789,440、重回 vs 卫冕、83.33 坐标命中）；维护约定第 40 条固化。⚠️ 页面与 8 张图都完整，**不进 G07 内容待补、不进 G08 视频样本**。

一句话结论：这条把库的取证从「永远不核实」推到「**有权威一手页就核，但核上了也不越界**」—— 一手已证实的只写第 1 名与系统参数，作者自算的仍标等效值，图面独有的仍标未逐项核实。最容易被漏的不是摘要太短，而是**核实成功之后顺手把整张表都当成已证实**。
