以下为基于 [A030](http://yb.woa.com/14N0XXeQcgj) 的归纳延伸：视频与解析稿都没有讨论取证方法。因与 [T068](../apps/「200KB%20的%20GIS」安装演示：六段命令%20×%20一手仓库逐条对照.html)（事实对照）、[T069](../apps/一手口径：GeoLibre%20是什么、真实安装链路、以及那些对不上的数字.html)（一手口径）性质不同 → 并列成卡。

**② 维护约定第 28 条再扩一层**：[A023](http://yb.woa.com/HvYlY3lwbsr) 把「专名 / 数字 / 语义三项回一手」扩成四项（加机构名单）；[A030](http://yb.woa.com/14N0XXeQcgj) 要再加一层 **「命令 / 仓库 / 依赖名 / 成功提示逐条回一手」**。原因：只查数字和专名会整段放行——这段解析稿里没有任何一个数字需要校正，横幅的 200KB / 3GB 甚至能在社媒文案里找到出处，但**流程本身是假的**。以后收到带终端 / 命令行 / 安装日志的画面，固定五步：查仓库存在性 → 回 README 对脚本与依赖 → 回产品定位对成功提示与启动命令 → 浮动面板 / 榜单数值留白 → 体积与 Star 按多期快照并列。见维护约定第 34 条。

**③ 「语义反转」要单独标**：`QGIS installed successfully.` / `Run: qgis` 不是普通专名错——它把**被替代的对象写成了安装产物**，与横幅「QGIS 3GB 安装包当场尴尬」自相矛盾。一类容易犯的圆场是「GeoLibre 能导入 .qgs 工程，所以装 QGIS 也说得通」，必须明确挡掉：**导入工程 ≠ 安装软件**。这与 [T038](../apps/数字的七类证据性质：演示%20·%20报价%20·%20示意%20·%20可核验计数%20·%20正文未载的图面结果.html) 第六类（42PB 内存→数据压缩）同属「数字/名词看着对、性质完全变了」，但这次连动作方向都反了。

**④ 与榜单线、Star 快照线的互照**：[A019](https://artificialanalysis.ai/video/leaderboard/image-to-video)（AA-Video Elo 单期截图）、[A025](https://mp.weixin.qq.com/s/6SkEqqZzXKECkn1gHRnnfQ)（GitHub Skills 飙升榜）都强调「榜单数字必须带抓取日 + 版本 + 筛选条件」。[A030](http://yb.woa.com/14N0XXeQcgj) 的「GisLibre-GitHub Trending」浮动面板更极端——**连项目名和 Star 数都没给**，只剩一个错名面板；而同话题视频号的 4.3k 星与一手实测 8815 又差了一倍。处理沿用 GC05：只追加不覆盖，做成时间序列，别把某个时点的数字写成规格。G24 的「Skills 飙升榜未回一手」与本次 G28 是同一类缺口。

**⑤ 归类与栏目克制**：库里已有 [A003](https://mp.weixin.qq.com/s/Jc-MFavK3WVRkDTjTLMT6Q) 六个 CAD 开源项目、[A009](https://mp.weixin.qq.com/s/1FVwM1cYFsyCkGtSAumS6A) 十个开源游戏、[A025](https://mp.weixin.qq.com/s/6SkEqqZzXKECkn1gHRnnfQ) 十个 GitHub Skills、[A029](http://yb.woa.com/3x1QBfsbpa6) 商业数字样机，加上 [A030](http://yb.woa.com/14N0XXeQcgj) 的浏览器 GIS，**开源项目类资料已经横跨 skill / game / cad / case**。这次仍按「不新建栏目」归 case 主板块、related 挂 skill / web3d / hardware——不因为来了个 GIS 就新开「地理信息」栏目。以后收到同类开源项目演示，沿用这条，避免栏目膨胀。

**⑥ 证据等级与缺口回写**：写「**一手项目开源可查（GitHub / 官网 / README）· 视频里的安装流程不可执行，不作为任何项目事实**」。新增 **G27**（GeoLibre 一手材料尚未正式收录）与 **G28**（Star / 体积 / 工具数多期快照与 Trending 面板数值缺）；case 板块追加 GC07–GC09（合成演示终端的命令级核验清单、开源项目多期快照口径、真实跑通 GeoLibre 的记录）；skill 板块追加 GSK06；G07 内容待补 12 → 13、G08 视频 6 → 7，G10 / G11 同步。

一句话结论：这条视频作为**产品资料**几乎全不可用（仓库 404、脚本不存在、成功提示反了），但作为**样本**补上了本库缺的一型——**连命令都是造的怎么办**：不要只校正文字和数字，先把画面里的命令拿去执行层面验一遍存在性；验完把「真实项目是什么」与「演示里演了什么」分成两张卡，中间不互相补台。
