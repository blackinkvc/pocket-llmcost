与 [T024](../principles/大模型的正确学习顺序：12%20阶段从入门到实战.html) 的 12 步是**两套不同的划分**（一个按工具链顺序、一个按能力阶段），同板块不同主题，故并列不合并。6 阶段逐条整理如下，图里的术语与拼写按原样保留：

- 阶段一 · 前置知识：编程基础 Python 熟练掌握；深度学习框架 PyTorch（目前学术界和工业界的主流）；数学基础 线性代数、概率论、微积分（理解梯度下降、矩阵运算）
- 阶段二 · 核心原理：卷积神经网络 CNN；Transformer（重中之重）——self-Attention 机制、多头注意力、掩码自注意力、交叉注意力，位置编码（Embedding）、前馈网络（FFN）、残差连接、层归一化；主流架构 Encoder-only: BERT（懂理解）/ Decoder-only: GPT 系列（懂生成，现在的主流）/ Encoder-Decoder: T5
- 阶段三 · RAG（检索增强生成）：数据索引（Indexing）进阶切分（Chunking）不能切切，要懂语义切分、重叠切分；向量化（Embedding）把文字变成向量，存入 Milvus / Faiss / Chroma。检索优化（Retrieval）是提升准确率的关键：Top-K 检索、混合检索（Hybrid Search）关键词检索（BM25）+ 语义向量检索互补优势点。重排序（Rerank）用高精度 Rerank 模型对初步检索回来的内容二次精排（必做）
- 阶段四 · Agent（智能体）：核心架构 ReAct——规划（Planning）思维链 CoT 把大任务拆解成小步骤；记忆（Memory）短期记忆（上下文）/ 长期记忆（向量库）；行动（Action）工具调用（Function Calling）让模型学会用搜索工具、计算器、API。五种设计范式 ReAct、Plan and Solve、Reflection、Tool Use、Multi-Agent。开发框架 LangChain、AutoGen、LlamaIndex、AutoGPT。MCP（前沿协议）
- 阶段五 · 预训练（Pre-training）：① 海量数据工程 TB 级数据的清洗、去重（Dedup）、质量筛选、数据配比（Data Mixture）；② 分词技术（Tokenization）词表大小（Vocab Size）权衡、SpecialToken 设计、Merge 高效化、Chunking 准确高效、多语言支持难点；③ 模型架构细节 RoPE（旋转位置编码）目前绝对主流（Llama 标配）、GQA（分组查询注意力）在训练速度和推理显存之间找平衡、RMSNorm（Pre-norm）比 LayerNorm 更稳定收敛；④ 分布式训练与加速 3D 并行：数据并行 DP 配合 ZeRO(1/2/3) 切分优化器状态/梯度/参数（显存救星）、张量并行 TP 单层切分通常用于节点内（Intra-node）、流水线并行 PP 层间切分用于跨节点（Inter-node）
- 阶段六 · 后训练（Post-training）：① 监督微调（SFT）指令构建 构造高质量 Instruction-Input-Output 数据对，全量微调算力允许下全参数更新效果最好；② 参数高效微调（PEFT）LoRA/QLoRA 目前最主流方案，低秩矩阵适配、极低显存、消费级显卡即可实现；Adapter Tuning 层间插入小网络；P-Tuning / Prefix-Tuning 优化输入端提示向量（Soft Prompt）；③ 对齐学习（Alignment）奖励模型（Reward Model）训练一个「判卷老师」给回答打分；RLHF 经典 PPO 算法（ChatGPT 同款）；DPO 直接偏好优化，无需奖励模型，直接用偏好数据优化，训练更稳定省资源；GRPO（deepseek r1 技术中使用的）、GSPO…（图面到此省略）

这张图把 [T024](../principles/大模型的正确学习顺序：12%20阶段从入门到实战.html) 里「RAG / Agent / 微调」三个词拆成了可查的技术清单，尤其适合当检查表用：比如做 RAG 时对照有没有 Chunking 策略、有没有混合检索、有没有 Rerank；做后训练时对照 SFT / PEFT / 对齐三段是否都覆盖。

图里把 MCP 标成「前沿协议」放在 Agent 阶段，说明它被视为 Agent 工具调用层的连接标准——这一点与 [T004](../agents/连接层三件套：代码索引、MCP·ACP%20协议与隔离沙盒.html)、[T021](../agents/Unity%20MCP：把%20MCP%20从「连工具」推到「直接操作游戏引擎」.html) 一致，但本图只给了一个名词，未展开。
