这一页出现的词，有些是论文里的原始叫法，有些是工程圈后来起的简称。
下表按「什么时候进来」排，一句话说清它是什么、现在站在什么位置。

释义只写到能判断「该不该用它」的深度，不展开推导。

| 概念 | 一句话释义 | 首次出现 | 现在的位置 |
| --- | --- | --- | --- |
| 多模态 Multimodal | 文本、图像、音频、视频在同一套表示里训练，而不是后拼一个视觉编码器 | 2021（CLIP） | 旗舰模型的默认形态 |
| MoE 混合专家 | 总参数很大，但每个 token 只激活其中一部分专家 | 1991 / 2021（Switch） | 主流开源模型的基本架构 |
| 自注意力 Attention | 每个 token 与前文所有 token 计算相关性，取代循环结构 | 2017（Transformer） | 所有主流模型的底座 |
| Prefill / Decode | 推理拆成两段：先并行读完整段提示，再逐字生成 | 2023 起成为工程口径 | 容量规划的基本单位 |
| KV Cache | 把已算过的键值缓存下来，避免每生成一个字重算前文 | 2020 前后 | 长上下文与显存的主因 |
| 上下文窗口 | 一次能读进多少 token，标称值与有效值差很远 | 2023 起成为卖点 | 百万级标称，有效长度另说 |
| 推理模型 / test-time compute | 把算力从训练挪到推理，让模型先想再答 | 2024-09（o1） | 被并回默认路由（GPT-5） |
| RLHF | 用人类偏好训练奖励模型，再据此调优输出 | 2017 提出 / 2022（InstructGPT） | 对齐的标准做法 |
| RLVR 可验证奖励 | 只对有标准答案的任务给奖励，数学与代码先被吃透 | 2025 | 推理能力提升的主路径 |
| 蒸馏 Distillation | 让小模型学大模型的输出分布，用算力换体积 | 2015（Hinton） | 小模型追平上一代旗舰 |
| 量化 Quantization | 把权重压到 8/4 bit，用精度换显存与速度 | 2022（GPTQ / LLM.int8） | 本地部署的默认手段 |
| 扩散模型 Diffusion | 从噪声逐步去噪生成图像，而不是一次画完 | 2015 / 2020（DDPM） | 图像视频生成的主流 |
| Agent | 把模型放进循环：调工具、读结果、改计划 | 2023-03（AutoGPT） | 编码场景率先跑通 |
| 工具调用 Function calling | 模型按 schema 输出结构化调用，由外部执行 | 2023-06（OpenAI） | 所有 Agent 的前提 |
| RAG 检索增强 | 先检索再生成，用外部文档补知识 | 2020（Lewis 等） | 长上下文部分替代了它 |
| MCP | 模型与外部工具之间的统一接口，工具方接一次全端可用 | 2024-11（Anthropic） | 事实标准，两万多个服务器 |
| Harness 运行脚手架 | 包住模型的那层循环与工具集，决定成绩与上限 | 2023 起在评测圈通用 | 2025 年成了产品差异点 |
| AI 编程 AI coding | 从补全一行，到接管整个 issue 的完整闭环 | 2021-06（Copilot） | Agent 最成熟的落地场景 |

## 读这张表的两个提醒

**时间是「被公开提出」的时间，不是「开始好用」的时间。** 后者通常晚一到两年。
带具体版本号的以官方发布为准，学术概念以论文首次公开为准。

**「现在的位置」这一列会过期。** 比如 RAG 那一行写「被长上下文部分替代」，
如果上下文成本和检索成本的关系再变一次，这句话就该改。前两列是历史，不会变。
