**一手交叉校验（仅用于标注偏差，不冒充视频画面）**：Epochal 官方公告《Introducing Time Portal》与工程文档（2026-11-24）、Bloomberg 报道（经 The Next Web / 财联社 / 腾讯新闻 / Quartz / Unite.AI / The Rundown AI 等转述）、MIT CS3 无关、Epochal 定价页与 API 文档。链接留 [A024](http://yb.woa.com/4AK3r0d8UHO).leadUrl，**不另建台账**（G23）。

**逐条对照**（视频说法 / 一手口径 / 差在哪）：

- **公司对得上**：Epochal 于当地时间 **2026-11-24** 正式亮相，首款产品 Epochal Time Portal（时光门户 / 时间传送门），CEO 张国栋 Guodong Zhang；官网原句「衡量智能的最佳标准，是预测未来的能力」「Today's AI has read almost everything and lived through almost nothing」「超人类水平的预测将重塑几乎所有行业，因为每一个决策都是一次预测」——视频那句引言属实
- **1 亿美元要降级**：一手是 **Bloomberg 援引匿名知情人士**称张国栋个人投入 1 亿美元，**Epochal 官方拒绝置评、无其他投资方披露**。视频写成「自掏腰包投资」的确定事实；另有中文号写「完成 1 亿美元融资」，两种转述并存，本库按一手口径标「单源未证实」
- **规模对得上但漏了一半**：一手为「>1 万亿存档页面、追踪 >7 万亿 URL、30+ 年历史、热门页版本粒度精确到分钟、90 天建成」，视频只给了 1 万亿 / 30 年。这些都是**厂商自述口径，无第三方核验**
- **「锁死在过去」讲浅了**：一手是 search / fetch / sandbox 三 API + `Accept-Datetime` 头；fetch 只返回 ≤ 指定时刻的最新快照，**取不到就报错、绝不拿更晚的副本替代**；Linux 微虚拟机的系统时钟、Ubuntu 镜像、apt / pip / uv / npm 软件源与全部出站流量都冻结在同一日期。视频只说了「网页检索」，没提沙箱环境这一层
- **2008 年金融危机是视频自举例，不是官方实验**：一手公开的预设示例是「1995 年底问『电脑能否击败最强人类棋手』→ 回答『还没有』；拨到 1997 年 5 月 → 『可以』」。正式自测是 **347 道 Kalshi / Polymarket 实时预测题**：先在结果揭晓前实时预测，数周后把截至时刻调回原始预测时间回放，比较两次**误差**——Time Portal 回放与原始实时误差相关性 **0.98**，用揭晓后实时网页 **0.16**，完全不联网 **0.49**。⚠️ 0.98 量的是**环境还原度（回放像不像当初）**，不是预测准确率；题目清单、误差分布、独立泄漏审计均未公开，公司也没公布预测准确率
- **团队基本对得上，两处要留白**：三位 xAI 创始成员张国栋、戴子航 Zihang Dai、Manuel Kroiss 属实；官方公告还列了 **Alex Bocharoff、Frank Luan** 两位；团队含 OpenAI / Anthropic / Google DeepMind 前员工属实。张国栋此前在 xAI 直接向马斯克汇报、负责 **Grok Code**（视频写「Grak Code」是拼写错）；Kroiss 负责预训练、曾有 DeepMind 背景。**「张国栋毕业于浙大 / 戴子航毕业于清华」在检索到的权威源里未逐人确认**，按视频说法原样留、不采信为事实。2026-02-02 SpaceX 全股票收购 xAI（合并估值 1.25 万亿美元、xAI 2500 亿），三人 3 月前后离职；到 3 月底 11 位非马斯克联合创始人全部出清，视频「2 月后陆续离职」方向对但简化了
- **工具链对得上**：命令行工具、Python / Rust SDK、控制台 playground、**MCP 服务器**、下一步做辅助决策的前沿模型——均见一手报道。免费额度极有限（每组织 100 次 search+fetch、1 小时 1vCPU/2GiB 沙箱，付费需联系销售），视频没提

⚠️ **必须主动补回的边界**：① 1 万亿网页**如何采集、是否取得授权，公司未披露**（数字存档行业法律灰区）；② 0.98 是**内部自测、保真度口径**，不是「AI 预测更准」；③ 外部请求冻结了，但**基座模型权重里的参数化泄漏（parametric leakage）堵不住**——智能体可能本来就记得历史结局；④ 没有自研模型发布时间表、没有独立评测、没有完整定价；⑤ 真正该等的是「在模型训练截止日之后才揭晓的题目上、带公开题单的准确率」。见 [T059](../agents/一手口径：Time%20Portal%20怎么防剧透，以及「0.98」到底量了什么.html) / [T060](../agents/「剧透」作为评测问题：单源报道、自编举例与本库三条%20Harness%20·%20环境线.html)。
