能做什么：让 Claude 和 Cursor 直接操作 Unity，建对象、连组件、写脚本，「一句话说完就帮你做完」。图卡上的原话是「AI 操作 Unity｜一句话完成开发」，画面里是 Unity 编辑器与 AI 对话框连线的示意。

权限边界是它最值得记的一点：只在自己的项目里开，权限握在自己手上，不用把代码传到别处。这和 [T004](../agents/连接层三件套：代码索引、MCP·ACP%20协议与隔离沙盒.html) 里「协议管连接与访问权、沙盒管隔离」是同一条思路，只是落到了游戏引擎上——也和 [T007](../apps/交付、审查与评测：AI%20写太快之后的质量闸门.html) / [T009](../apps/CAD%20的%20AI%20化落地：四条工作流与人工复核红线.html) 反复出现的「Agent 得能看见自己做出来的东西」呼应。

与 CAD-MCP（[T008](../agents/六个%20CAD%20开源项目横向对比：工作流、门槛与天花板.html)）的对照：两者都是把 MCP 接进一个重客户端（AutoCAD / 浩辰 / 中望 ↔ Unity），都强调本地连接与截图/句柄回读；差别是 CAD-MCP 停二维绘图，Unity MCP 面向完整 3D 工程与脚本。后续若收到更多「MCP + 具体软件」的资料，相近内容并入本卡，不同软件并列补要点。
