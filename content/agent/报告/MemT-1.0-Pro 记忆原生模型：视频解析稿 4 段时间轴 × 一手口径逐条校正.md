**一手来源交叉校验**（本卡最关键的一层）：本轮检索到发布方官方公众号「记忆张量MemTensor」《相隔月余 大有新忆：MemT 1.0 Pro 来了，554B 发布并开源》、HuggingFace 模型卡与 GitHub README、arXiv 2610.26825 技术报告线索，以及新民晚报（腾讯新闻转载）、澎湃新闻、极目新闻、环球网、感知上海（上海市政府外宣）等多家报道。⚠️ 以下**只用于校正解析稿口径、不冒充视频画面内容**；这些外部来源尚未单独建台账，链接留作线索：

- **专名误写 ①**：解析稿写「MemmTensor」→ 实际是 **MemTensor（记忆张量）**，上海基座模型公司；视频号页面标题、官方公众号、所有权威报道均用 MemTensor
- **专名误写 ②**：「Memm-T-1.0-Pro」→ 实际 **MemT-1.0-Pro**（系列还有 Nano / Flash）
- **专名误写 ③**：「MemmT-AgentBench (MAB)」→ 实际是 **MemoryAgentBench**，ICLR 2026 的第三方记忆评测基准（评检索、测试时学习、长程理解、选择性遗忘），**不是发布方自家的榜**；缩写 MAB 在一手来源里查不到。另一项长历史评测是 **BEAM-1M**（信息提取 / 矛盾处理 / 信息更新 / 偏好遵循 / 摘要 / 时间推理等十类能力）
- **数字误读**：「Memory AgentBench 评分 **23.67**」→ 官方技术报告与多家媒体一致为 **23.87**（较 Flash 提升 6.51 分）；BEAM-1M 为 **41.80**（提升 4.76 分）
- **OCR 双重错乱**：「11 项**参数比**评测得分 **S5.08**」→ 实际是 **11 项记忆评测平均得分 53.08**，在「参数化记忆方法」这一类里居首。S5.08 是 53.08 的形近误读，「参数比评测」是「记忆评测」的错乱
- **语义错置 ①（最关键）**：「Agent 经验写入**提供持续微调**」「经验直接写进模型」→ 官方明确 **在线交互时模型主干与超记忆权重保持固定，交互结束后只更新动态记忆状态，无需每轮重新训练模型**；训练阶段才更新那 4.23B 可训练记忆参数。写进的是**运行时记忆状态**，不是改权重、不是持续微调
- **语义错置 ②**：「**13M 内部记忆**」→ 13M 是**动态记忆状态的大小**（约 13M 状态量），不是 13M token 上下文、也不是 13M 参数；视频号页面标题写「动态记忆状态仅 13M」是对的
- **语义错置 ③**：「文本长度压缩率倒数仍领先」「固定状态会话绵延 不断更新 RAG」「记忆节流机制 RAG」→ 一手口径里对应的是：记忆状态**体积固定不随对话轮次膨胀**、交互结束后更新动态记忆状态、128K 历史场景下相比完整 KV Cache 存储开销降低约 **66 倍**、记忆写入采用 **Gated DeltaNet-2（GDN-2）** 稳定性改进机制。解析稿这几句语义不通、疑似 OCR 与机翻拼接，按原样保留但不解读
- **描述里没出现、但页面标题主动给的边界**：「但固定状态仍可能丢失细节」——官方与二手解读也都承认：在需要大量精细证据检索的超长历史任务上，部分纯文本记忆检索系统整体表现仍占优

**官方口径下的完整参数与结果**（供对照，全部标为发布方口径）：基于 **NVIDIA Nemotron 3 Ultra** 底座，**554B 总参数 / 59B 激活参数 / 4.23B 可训练记忆参数 / 13M 动态记忆状态**；训练用 NVIDIA Megatron-Core + Megatron Bridge、34B token 数据集、持续预训练 + 后训练两阶段；HuggingFace 开源，许可 **OpenMDW-1.1**，支持 Transformers / vLLM / SGLang / Docker 与 OpenAI 兼容 API。评测：BEAM-1M **41.80**（+4.76）、MemoryAgentBench **23.87**（+6.51）、11 项记忆基准平均 **53.08**。公司实测口径：长期测试任务完成率提升约 **30%**、token 消耗减少 **60–70%**。10 月底先发 Nano（36B，Qwen 底座）与 Flash（288B，DeepSeek 底座），HF / GitHub 日均下载超 1 万次；发布后登上 X 科技话题 Trending 榜 #MemT。详见 [T045](../agents/MemT-1.0%20系列技术整理：四层参数、记忆模块、训练法与可维护性边界.html)。
