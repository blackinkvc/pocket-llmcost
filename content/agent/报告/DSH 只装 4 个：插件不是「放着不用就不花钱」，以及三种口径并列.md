**四个插件（按正文顺序）**：① **dsh-market**（插件市场）——「如果只能先装一个，就是它」；把市场内嵌进设置页，可直接搜、一键安装，省掉终端敲命令和核对仓库地址；正文写「**据说**里面能搜到近 9000 款、精选两千多」，并自己标注「据说」，本库照留不核实；结论「先有商店，再谈装修」。② **Better Sidebar**——把文件树、代码编辑器、终端、Git 面板塞进右栏，解决原侧栏「文件只能看不能改」，看 AI 输出和改代码不用来回切窗口；作者称这是「手」。③ **dsh-context**——把当前对话里历史记录、系统提示、文件引用各占多少 token 摊开；「它不帮你删，但你能一眼看出是谁把窗口挤爆的」，作者称这是「表」。④ 长对话用 **billion context** 这类——上下文快满时自动压缩成摘要，价值是「不打断」（不用手动开新会话、也不用自己总结前情）；也可用记忆类插件 **MemSearch**（每聊一轮自动记笔记、第二天新开对话能接着干），**两类二选一就行，别都装**。

**核心论点（正文按原样）**：为什么是四个不是十个？因为「AI 要在需要时调用插件，前提是它得知道有哪些、每个能干什么——所以**每装一个，系统提示里就多一段描述**。插件不是『放着不用就不花钱』，它们一直在占着每次对话的输入」。作者引小红书一篇笔记开头：「不按需装，token 和余额的消耗速度会非常惊人」，并评「这句比后面列的十个插件都值钱」。收尾给了一道数字题：「你现在 DSH 里装了几个插件？常用的几个？报两个数，评论区说说。我猜是『装了 8 个，常用 2 个』。那 6 个不是白装——它们确实在花你的钱，只是不产出。」

⚠️ **三种口径并列保留，不调和**：

- [A026](https://mp.weixin.qq.com/s/TUMmu9eeJyEaWsitwfCMmQ)（11-16）：**必装 10 大插件**，封面列 10 个、内页还出现更多插件名
- [A027](https://mp.weixin.qq.com/s/gJJJaFpsDD2m3qlXGMcxvA)（11-20）：**只装 4 个**，多装是给每次对话加税，理由是系统提示常驻占用输入 token
- [A012](https://mp.weixin.qq.com/s/A2fnlab0SoLoAGQJwlmZyg) → [T031](../agents/DeepSeek%20Harness（dsh）两个月重度实测：迁移决策、五页图全量与对比数字.html)（11-23）：作者两个月重度实测后的建议是「下载 dsh、**把所有插件都装上**」

三条来自不同作者、不同立场（推荐清单 / 成本论证 / 个人实测），**不替读者判断谁对**；但可以把差异的**机制**写清楚：[A027](https://mp.weixin.qq.com/s/gJJJaFpsDD2m3qlXGMcxvA) 指出的是「插件描述常驻系统提示」这一固定成本，[A026](https://mp.weixin.qq.com/s/TUMmu9eeJyEaWsitwfCMmQ) / [A012](https://mp.weixin.qq.com/s/A2fnlab0SoLoAGQJwlmZyg) 强调的是能力覆盖，两者并不必然矛盾（装得多 ≠ 每次都调用），本库只记到这一层，不做性能结论。

**口径边界**：① 「近 9000 款 / 精选两千多」是正文自己标「据说」的转述，未给来源，不核实；② 「装了 8 个、常用 2 个」是作者**猜测的示例数字**，不是统计；③ 「token 和余额消耗速度惊人」引自小红书笔记，笔记标题 / 作者 / 链接全未给；④ 没有给任何实测 token 数、单价或账单，**不补、不估算**；⑤ Better Sidebar / billion context / MemSearch 的仓库、作者、版本、许可未给；⑥ 图面 9 页分页与正文重复，不重复计数。

**与本库的互照**：这条把「Skill / 插件的隐性成本」补进了本库——[A009](https://mp.weixin.qq.com/s/1FVwM1cYFsyCkGtSAumS6A) 与 [T061](../agents/GitHub%20Skills%20本周飙升榜%20TOP%2010：热度是入口，价值要放回具体任务.html) 都在数「有多少个、能干什么」，[A027](https://mp.weixin.qq.com/s/gJJJaFpsDD2m3qlXGMcxvA) 补的是「每多一个要付多少常驻成本」。和 [A022](https://mp.weixin.qq.com/s/udXF9FEP6SCyeqIxo0YqWA) 的 RAG 规模账（元数据占 10–30%、副本成倍增加）、[A014](https://mp.weixin.qq.com/s/930qfWClyp1PJSKNSe9B5w) 的麦田「演示数据」一样，属于**别把清单当结论**的一类。以后收到 Harness / Skill 成本实测，按同主题并入本卡，不新建重复卡。
