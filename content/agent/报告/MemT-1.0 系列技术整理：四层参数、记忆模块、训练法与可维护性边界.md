以下为基于 [A020](http://yb.woa.com/DjfzMFlnxuO) 的一手来源交叉校验整理（非视频画面内容），把散在官方公众号、HF 模型卡、二手深度解读里的技术信息按「参数 / 架构 / 训练 / 评测 / 边界」五层归并，方便以后同类文章往里并。与 [T044](../agents/MemT-1.0-Pro%20记忆原生模型：视频解析稿%204%20段时间轴%20×%20一手口径逐条校正.html)（口径校正与资料形态）同板块不同主题 → 并列成卡。

**① 四层参数要分开读**（最容易被混成一个数）：

- **554B 总参数**：整个模型容量，来自底座 NVIDIA Nemotron 3 Ultra（550B 级 MoE）
- **59B 激活参数**：每 token 的算力开销，约 10.6% 激活率
- **4.23B 可训练记忆参数**：训练阶段真正更新的「记忆能力旋钮」，不到整体的 1%；**在线交互时这块也冻结**
- **13M 动态记忆状态**：运行时状态，会话里发生的事先落在这里、会话结束再写回，体积固定不随轮次膨胀。二手深度解读把 Pro 的记忆空间写成约 **48 MiB**（Flash 为 1280 MiB、缩小 26 倍多），这一组数字来自自媒体解读、本库按二手口径标注，未去 HF 模型卡逐项复核

**③ 训练法**：持续预训练 + 后训练两阶段，34B token 数据集，Megatron-Core / Megatron Bridge 做分布式训练；记忆写入用基于 **Gated DeltaNet-2（GDN-2）**、经稳定性改进的 token 级更新机制。最妙的一段是**老师–学生蒸馏**：同一个底座，老师不带记忆模块、把全部聊天原文摆进去（开卷），学生带记忆模块、原文读一遍就收走只剩内部状态（闭卷），目标让学生答案尽量像老师；答错的差距顺着往回找到「取」和「写」两步，分别微调那几个开关——从头到尾没人告诉学生该记什么。554B 底座整个冻住，只训新接的记忆模块。

**④ 效果与部署**：128K 长度历史场景下，相比完整上下文 KV Cache 存储开销降低约 **66 倍**；记忆状态文件可保存、可离线恢复会话，加载后不需要原始对话记录即可复现历史记忆效果。支持 **Experience-Guided Agentic Coding**：把历史任务经验存进原生记忆，执行编码任务时通过记忆注意力调取，不用把经验文本追加到任务上下文。HF 开源、许可 OpenMDW-1.1，Transformers / vLLM / SGLang / Docker 可直接部署，提供 OpenAI 兼容 API 与本地 GPU 示例代码。公司给出的长期测试口径是任务完成率提升约 **30%**、token 消耗减少 **60–70%**（均为发布方口径，未独立复现）。

**⑤ 评测与边界**（读分之前先看这几条）：

- BEAM-1M **41.80**（较 Flash +4.76）、MemoryAgentBench **23.87**（+6.51）、11 项记忆基准平均 **53.08**；Pro / Flash / Nano 在**参数化记忆方法这一类里**分列前三，不是跟所有记忆方案比
- **53.08 绝对值刚过半**：说明「把记忆训进权重」还在早期，能稳定带来相对提升，但离「记住就等于答对」还远；BEAM-1M 41.80 也说明长历史召回仍有明显缺口
- **跨版本不能直接归因**：Nano 用 Qwen 底座、Flash 用 DeepSeek 底座、Pro 用 Nemotron 3 Ultra，Pro 分高无法完全排除底座功劳。官方补了 Nano 对照：只把记忆空间从一块加到四块，平均分涨 1.14；空间不动、只把写入频率从每 token 一次降为每轮一次，平均分掉约 6 分——结论是**记忆效果关键在怎么写、写多频，不在空间多大**
- **外部记忆仍不可替代**：官方自己写「在需要大量精细证据检索的超长历史任务上，部分纯文本记忆检索系统整体表现依旧占优」；视频号页面标题也写「固定状态仍可能丢失细节」。正确用法是**分担一部分**而非全面替代——短期事实、用户偏好、频繁复用的结论适合进权重；需要审计、撤回、多人共享的内容仍该留在外部
- **可维护性是最大代价**：外部记忆改一条记录是秒级写操作、可留痕；参数化记忆改一个错误是一次训练，成本按卡时算、周期按天算。「写进去容易，删掉难」
- **口径不可直接对撞**：外部记忆方案在别的报告里能到 61%、MemoryAgentBench 原论文最佳系统 49.6 这类数字，任务、脚手架与评分口径都不同，不能与 23.87 直接比高低

**系列与时间线**：10 月底首次发 MemT 1.0（Nano 36B / Flash 288B），登陆 HuggingFace、GitHub 后日均下载超 1 万次；11 月 22–24 日发 Pro（554B）并开源，登上 X 科技话题 Trending 榜 #MemT。二手解读里提到有团队用它做个人记忆工具、情感陪伴硬件与多智能体协作，按原样记录、未核实。

⚠️ 未给 / 未核实：11 项基准逐项名称与分数、评测脚本版本与脚手架、48 MiB 与 1280 MiB 的原始出处、34B token 数据集构成、第三方独立复现、66 倍与 30%/60–70% 的测试条件。凡二手解读给的数字都标了性质，不写成官方口径。
