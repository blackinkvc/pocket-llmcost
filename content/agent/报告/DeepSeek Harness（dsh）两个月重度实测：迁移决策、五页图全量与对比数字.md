- 4/5：分工比喻——能力强的去啃硬骨头、能力中等但卖力的是中坚力量、能力差但忠诚的安排点杂活；蓝字「DeepSeek 目前就属于能力中等但卖力」。可用 magpie 分配路由，甚至用免费模型干杂活、DeepSeek 监控 + 干活、opus 或 gpt 做最后验收。行业判断：国内大部分公司已过了死盯 token 消耗的疯狂阶段，更多是「什么能力水平的模型就干什么样的事」；把 AI 的模型和工具资源分配好，跟把团队各种人才资源分配好一样重要且必要
