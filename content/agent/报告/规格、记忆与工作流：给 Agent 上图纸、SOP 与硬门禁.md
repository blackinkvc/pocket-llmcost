- 规格与记忆：用 OpenSpec、Mindfold Trellis 一类工具把需求、约定、历史决策写成图纸与交接本，让新会话不必从头交代背景
- 工作流：把「先规格、再实现、后验证」变成固定步骤，而不是靠模型临场发挥
- 硬门禁（Hooks）：测试不过直接锁死、不准提交——把质量约束从「提示词建议」升级成「系统强制」，这是该层最有价值的一点

与 [T001](../agents/科研分析路线规划%20Skill：工作流与输入输出契约.html) / [T002](../agents/从该案例提炼：Skill%20设计的三条可复用原则.html) 的关系：那两卡讲单个 Skill 的输入输出契约与设计原则，本卡讲的是多个 Skill / 规格 / 门禁如何组成一条可交付的流水线。同板块、不同主题，故并列；后续若收到讲 Skill 触发条件、编排或长期记忆的资料，按相近程度并入。

可迁移判断：一个 AI 工作流是否可靠，看约束是写在提示词里（可忽略）还是挂在钩子上（绕不过）。

> 整理说明：原文仅以「如 OpenSpec、Mindfold Trellis」举例，未说明二者功能差异或安装方式；不做推测。
