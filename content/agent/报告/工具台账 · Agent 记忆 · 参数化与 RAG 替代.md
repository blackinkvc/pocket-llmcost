### MemT-1.0-Pro（记忆原生大模型）

把历史编码进内部记忆，记忆写入与读取变成可训练能力，后续回答无需在上下文保留历史原文。554B 总参数 / 59B 激活 / 4.23B 可训练记忆参数 / 13M 动态记忆状态；

— 作者：记忆张量（MemTensor）与 NVIDIA 联合研发 / 开源 · 平台：基于 NVIDIA Nemotron 3 Ultra； · 开源：开源（OpenMDW-1.1）

> ⚠️ 评测为厂商自测，「居首」仅限参数化记忆方法类内；53.08 绝对值刚过半，官方自己写在需要精细证据检索的超长历史任务上纯文本检索系统仍占优、固定状态仍可能丢失细节。视频解析稿把专名、数字、语义都写错了，见 T044 / T045 / T046

### MemT 1.0 系列：Nano / Flash

Pro 之前的两个轻量版本，日均下载超 1 万次；二手解读提到被用于个人记忆工具、情感陪伴硬件与多智能体协作。官方对照实验用 Nano：只加记忆空间平均分涨 1.14

— 作者：记忆张量（MemTensor） · 平台：2026 年 10 月底首发，登陆 HuggingFace 与 GitHub； · 开源：开源

> ⚠️ 三个版本底座不同（Nano=Qwen / Flash=DeepSeek / Pro=Nemotron 3 Ultra），跨版本分数无法完全排除底座功劳，不能直接当作「记忆机制 alone 提升」的证据。48 MiB / 1280 MiB 记忆空间来自二手解读，标未复核，见 T045

### MemoryAgentBench（ICLR 2026 记忆评测基准）

用于检验长历史下模型能否真正调用记忆，是记忆类模型最常引用的硬基准之一；原论文最佳系统约 49.6，另有厂商自报 62.19

— 作者：第三方学术基准（Hu 等，ICLR 2026）；非 MemTensor 自有榜 · 平台：评测检索、测试时学习、长程理解、选择性遗忘四类记忆能力；

> ⚠️ 视频解析稿写成「MemmT-AgentBench (MAB) / 评分 23.67」，专名与数字都错；不同报告的评分口径与脚手架不同，23.87 不能与 49.6 / 62.19 直接比高低。已列为榜单雷达页 L21 候补，见 T044 / T046

### BEAM-1M（百万 token 级长历史记忆评测）

不只测「能否找到一个事实」，还测历史发生变化与关系后的处理；与 MemoryAgentBench 一起构成长历史记忆的两条主要评测线

— 作者：第三方学术基准（据 MemTensor 官方公众号说明） · 平台：覆盖信息提取、矛盾处理、信息更新、偏好遵循、摘要、时间推理等十类长历史记忆能力；

> ⚠️ 41.80 说明长历史召回仍有明显缺口；分数来自厂商技术报告自测、未独立复现。视频解析稿完全没提到这一项，属漏项，见 T044 / T045

### Gated DeltaNet-2（GDN-2）记忆写入机制 / 动态记忆状态

128K 历史场景下相比完整上下文 KV Cache 存储开销降低约 66 倍，记忆状态体积固定不随轮次膨胀；配合「记住 / 更新 / 调用」三个可训练动作与老师–学生蒸馏

— 作者：MemTensor 技术报告（经稳定性改进）；机制类条目，非独立工具 · 平台：每轮或每段结束做 token 级记忆更新；memory attention

> ⚠️ 视频解析稿把这块写成「记忆节流机制 RAG」「经验写入提供持续微调」，都是语义错置：官方明确冻结主干、不每轮重训。66 倍与 30% / 60–70% 均为发布方口径，见 T044 / T045
