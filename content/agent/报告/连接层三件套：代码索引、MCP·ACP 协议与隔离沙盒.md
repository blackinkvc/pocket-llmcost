- 代码索引（Tree-sitter / LSP）：像超级目录，让模型不必把整个仓库塞进上下文也能秒级定位代码，是「上下文工程」的地基
- MCP / ACP 协议：像万能插座，把外部工具、数据源以统一方式接进来，避免为每个工具写专用适配；它管的是「连接与访问权」，不是推理本身
- 沙盒（E2B / Docker）：像防爆实验间，给执行环境做隔离；代码跑崩了也不伤及真系统，让 Agent 敢跑、敢失败、敢重试

三者的分工可以这样记：索引给「眼睛」（看得见代码），协议给「手」（够得着工具），沙盒给「防护」（出事不扩散）。少任何一件，Agent 要么瞎、要么够不着、要么不敢动。

对 MCP 板块的补充认知：文章把 MCP 与 ACP 并列为协议层，说明连接标准不是只有一家；后续若收到专门讲 MCP 规范、安全边界或工具/资源/提示三类原语的资料，相近内容并入本卡，不同主题再并列。
