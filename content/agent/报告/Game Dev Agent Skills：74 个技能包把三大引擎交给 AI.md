同源详版补充：仓库 gamedev-skills/awesome-gamedev-agent-skills，9.2 千星，74 个技能包覆盖 Godot、Unity、Unreal 三大引擎；装进你的 AI 工具里，等于请了个随叫随到的游戏导师，卡在哪一步直接问它。作者把它和 Unity MCP 一起列为「把工具交给 AI，让它替你动手」的压轴两个。

与同板块其他卡的关系（故并列、不合并）：[T001](../agents/科研分析路线规划%20Skill：工作流与输入输出契约.html)/[T002](../agents/从该案例提炼：Skill%20设计的三条可复用原则.html) 讲单个 Skill 的输入输出契约与设计原则；[T008](../agents/六个%20CAD%20开源项目横向对比：工作流、门槛与天花板.html) 是 CAD 领域六个开源项目横评；[T015](../agents/30%20个%20Skill%20清单：可见的前%2010%20个与逐条详情卡.html) 是 WorkBuddy 办公场景 30 个 Skill 清单；[T013](../agents/Skill%20形态三项目：把资料与代码变成可复用能力.html) 是知识图谱类 Skill。本卡是**游戏开发垂直领域的技能包合集**，触发场景、交付物与前三组都不同。

可迁移判断：一个技能包合集值不值得装，看它是否覆盖你已在用的引擎、是否按「卡在哪一步」组织，而不是只看技能数量。74 这个数字之所以有用，是因为它对应三大引擎的完整工作流，不是堆数量。

> 整理说明：「游戏原型快速生成」是图卡小窗里的字样；仓库与覆盖引擎来自同源详版文字，已标注来源性质。
