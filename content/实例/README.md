## 和「研究」的区别

- **实例**：我做的东西，重点是**迭代过程**——第几版、改了什么、为什么改、当时踩了什么坑。
- **研究**：看别人的东西，重点是**结论和证据**，产出一篇篇可署名的报告。

同一件事两边都能写，但角度不同：实例写「我怎么改的」，研究写「这类做法为什么有效」。
