2026-11-18 · 选型 · 成本

不按榜单选，按约束选

六个维度按对实际成本的影响排序：许可证、上下文、单价、吞吐、工具调用、可部署性。榜单只解决其中一个。

榜单回答的是「谁强」，选型要回答的是「谁在我这里不坏」。下面六项按对实际成本的影响排序， 前三项经常被忽略，后三项经常被高估。

1. 许可证

开放权重不等于可商用。先看条款，再看能力：能不能商用、能不能改、有没有月活门槛、衍生物要不要同样开源。 许可证选错，后面所有优化都白做。

2. 上下文

标称长度 ≠ 有效长度。跑长文任务时要做「针在草堆里」测试：把关键信息放在第 1 万、5 万、10 万 token 处， 看模型还能不能取出来。有效长度通常显著小于标称值。

3. 单价

输入和输出分开计，推理模型的输出 token 往往更多（思考过程也算钱）。 按月估算时别只看单价，看「单次任务总 token × 调用次数」。

4. 吞吐

Agent 场景看并发上限和首 token 延迟，不只看单次输出质量。 一个慢 3 秒的模型，在十步工具调用里就是 30 秒体感差距。

5. 工具调用

结构化输出稳不稳定，决定 Agent 能不能落地。测试方法：给 20 个带嵌套 schema 的工具， 看它连续 10 轮调用后有没有漏参数、错字段、编造不存在的工具。

6. 可部署性

能不能私有化、量化后掉多少，决定长期成本。7B 级模型量化到 4bit 通常可接受， 70B 以上要算显存与并发的账。
